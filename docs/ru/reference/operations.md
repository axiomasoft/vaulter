# Каталог операций

Каждая изменяющая запись проходит через [конвейер операций](/ru/concepts/operations) под именем
(`<модуль>.<группа>.<глагол>`). Каждый активный модуль объявляет **политику** для каждого принадлежащего ему
имени ([ADR-0032](/adr/0032-operation-catalog-and-concurrency)); ядро собирает их в `OperationCatalog`.
`OperationRunner::write()` отклоняет изменяющую операцию, имени которой нет в каталоге, через
`UnknownOperationException` — до claim ключа и до транзакции, — поэтому новая запись не выйдет без ответа на
вопрос, как она защищена от потерянных обновлений и повторов. Два установленных модуля с одним именем — это
недопустимый граф модулей.

Напечатать каталог установленного приложения:

```bash
php artisan vaulter:operations          # таблица Markdown
php artisan vaulter:operations --json   # {"operations": [{operation, module, aggregate, ...}]}
```

## Политики

**Конкурентность** — как запись защищена от параллельной ([Конкурентность](/ru/reference/concurrency)):

| Значение | Смысл |
|---|---|
| `if_match` | меняет существующий агрегат по его версии; `If-Match` обязателен (`428` без него, `412` для устаревшего тега) |
| `append` | создаёт новую строку; версии для сравнения нет, `If-Match` не нужен |
| `natural` | абсолютная установка или изменение членства; повтор даёт тот же итог (star, флаг хранения) |
| `state_machine` | переход, проверяемый против текущего состояния под блокировкой (загрузки) |
| `generation` | fence поколения коллаборации (`409 collaboration_*`) |
| `row_identity` | удаляет неизменяемую строку по id; второй раз — `404` |

**Идемпотентность** — чем безопасен повтор ([Идемпотентность](/ru/concepts/idempotency)):

| Значение | Смысл |
|---|---|
| `receipt` | запись захватывается и сохраняется под `Idempotency-Key`; маршрут несёт middleware ключа |
| `natural` | повтор без ключа не даёт второго эффекта |
| `conditional` | повтор отвечает по предусловию (content `PUT` с тем же `If-Match` даёт `412`) |
| `protocol` | машинный протокол со своей дедупликацией (хаб коллаборации, смещения Tus) |

## Проверки

В каждом модуле с операциями есть `OperationPolicyCoverageTest`: каждое имя операции в исходниках есть в
каталоге; каждый изменяющий маршрут `vaulter.v1.*` пакета входит ровно в одну политику; каждый маршрут `receipt`
несёт middleware `Idempotency-Key`; каждый маршрут `if_match` отвечает `428` без `If-Match`.
