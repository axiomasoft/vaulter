# Что такое DocVault?

**DocVault** — открытый Laravel-пакет для встраивания полноценной системы управления
документами в существующее приложение. Идея выросла из модуля совместного редактирования
во FlexCRM, где редактор TipTap синхронизируется через серверный хаб с хранением версий в
формате JSON в базе данных. DocVault выносит эту инфраструктуру в переиспользуемый
компонент, пригодный для встраивания в любой Laravel-проект с собственной системой ролей.

## Ключевые концепции

| Концепция | Описание |
|---|---|
| **Document** | Единица контента (текст, таблица, презентация…), хранится как TipTap JSON. |
| **Version** | Снапшот при сохранении; цепочка версий образует историю. |
| **Folder** | Иерархическое дерево папок (как Google Drive / Яндекс Диск). |
| **Workspace** | Изолированное пространство документов, привязанное к сущности приложения. |
| **Permission Context** | Адаптер, через который DocVault обращается к вашей системе ролей. |

## Требования

- PHP `^8.4`, Laravel `^12` или `^13`
- Vue `3` для фронтенд-компонентов
- Node `>=20` для сервера совместного редактирования и сборки
