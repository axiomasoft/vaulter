# Скомпрометированный артефакт

Процедура для владельца host-приложения. Страница описывает действия, но не разрешает и не исполняет их.

## Симптом

Digest пакета/образа расходится с утверждённым provenance, утекли build/signing credentials либо release/dependency признан вредоносным.

## Диагностика без изменений

Зафиксируйте package/version, immutable digest, source commit и редактированные CI/provenance evidence. Сравните lockfile/манифест с deployment без установки или исполнения подозрительного кода. Проверьте registry metadata доверенным read-only способом. Доказательства храните с ограниченным доступом. Общая работоспособность приложения не доказывает целостность артефакта; doctor не сертифицирует отзыв в registry.

## Ограниченное действие

До замены deployment или изменений registry/CI требуются явное разрешение владельца и проверенная копия. Изолируйте затронутые deployment и release pipelines, запретите новые установки версии по owner registry policy, поместите caches/artifacts в карантин с сохранением evidence. Используйте приватный процесс SECURITY.md репозитория; секреты, закрытые детали реализации и данные клиентов не публикуйте.

Перед registry-действиями владелец должен проверить актуальную первичную документацию сервиса. Packagist abandon не равен security yank/revoke. Удаление OCI tag не отзывает digest и скачанные копии. Команды Vaulter artifact-revoke нет. Через приватную систему смените затронутые CI/publishing credentials, изучите их использование и соберите проверенное исправление из доверенных inputs в чистом pipeline. Уведомления и disclosure согласуйте приватно: этот runbook не исполняет и не квалифицирует операции.

## Проверка результата

Сверьте новый immutable digest/provenance с одобренным source/lockfile. Инвентаризируйте deployments/caches и отметьте потребителей с плохим digest. Получите owner evidence действия installation controls и отзыва credentials. HTTP-результат приложения не доказывает containment или удаление из downstream caches.

## Откат

Если изоляция нарушила доступность, разверните только проверенную чистую версию по [runbook отката](./release-rollback). Не возвращайте скомпрометированный артефакт или ключ. Сохраните карантин/evidence; излишне широкий запрет установки отменяет владелец после проверки чистой замены.
