# Ошибки, неподдерживаемые и защищённые паролем файлы

Сканирование завершается одним исходом на ревизию файла. Что можно делать оператору, зависит от него:

| Исход | Значение | Действие |
| --- | --- | --- |
| clean | опубликован | нет |
| failed | ошибка или таймаут сканера | повторить |
| unsupported | сканер не читает формат | решать по политике; повтор даст тот же результат |
| password protected | содержимое нельзя проверить | попросить владельца загрузить файл без пароля |
| infected / quarantined | вердикт против содержимого | **никогда не снимается массово** |

Повторяйте только failed-ревизии, предварительно посмотрев список:

<!-- snippet: shell -->

```bash
php artisan vaulter:scan:rescan --retry-failed --dry-run --tenant=acme --drive=1
```

<!-- snippet: shell -->

```bash
php artisan vaulter:scan:rescan --retry-failed --tenant=acme --drive=1 --reason="scanner outage"
```

Не снимайте карантин массово; решайте по каждой ревизии отдельно.

## Диагностика и восстановление

1. Запишите ревизию, версию сканера, результат и время проверки. Проверьте очередь, сокет демона и фактическую версию ClamAV через `vaulter:doctor --check=drive.scan.scanner`.
2. Восстановите воркер или демон и проверьте сканирование разрешённого тестового файла. Просмотрите список повторов для затронутого tenant и диска перед запуском.
3. Проверьте новый результат и политику скачивания каждой затронутой ревизии. Действующая политика применяется к неподдерживаемым, зашифрованным и карантинным файлам, пока владелец не предоставит безопасную замену.
