# Глоссарий

| Термин | Значение |
| --- | --- |
| **Drive (диск)** | Файловое пространство одного владельца (любая Eloquent-модель с `HasDrives`). Открывается `Vaulter::drive($owner)`. |
| **Profile (профиль)** | Именованная политика диска: хранилище, квота, правила загрузки, драйвер прав, включённые функции. См. [Диски и профили](/ru/concepts/drives-and-profiles). |
| **Node (узел)** | Папка, файл или документ в дереве диска. |
| **Revision (ревизия)** | Одна неизменяемая версия содержимого файла или документа. |
| **Blob** | Адресуемые по содержимому байты в `vaulter-media`, разделяемые согласно области dedup. |
| **Dedup scope** | Где одинаковые байты могут делить один blob: `tenant`, `drive` или `off`. |
| **Tenant (тенант)** | Граница изоляции мультитенантного хоста. См. [Мультитенантность](/ru/concepts/tenancy). |
| **Actor** | Пользователь, от имени которого действует handle диска (`actingAs`). |
| **Grant** | Право на узел, выданное субъекту. |
| **Ability** | Вычисляемая возможность (`view`, `comment`, `edit`, `manage`, `delete`), передаваемая клиенту. |
| **Permission driver** | Компонент, решающий доступ: `database`, `gate`, `spatie`, `null` или ваш. |
| **Outbox** | Строки событий, записанные в одной транзакции с изменением; источник доставок вебхуков. |
| **Delivery** | Серия попыток отправить одно событие одному endpoint вебхука. |
| **Scan obligation** | Устойчивое обязательство получить вердикт сканера для ревизии файла. |
| **Inspector** | `UploadInspector`, проверяющий загрузку до её принятия. |
| **Hub** | Сервер протокольного адаптера коллаборации; эксплуатация коммерческого дополнения описана в его приватном руководстве. |
| **Receipt** | Зафиксированное подтверждение бэкенда об одном обновлении коллаборации; только квитанция делает правку *сохранённой*. |
| **Checkpoint** | Слитое Yjs-состояние и JSON-проекция, которые хаб публикует из журнала обновлений; журнал до него затем удаляется. |
| **Pending marker** | `(поколение, through_seq)` на документе, чьи сохранённые правки коллаборации ещё не в чекпоинте; пока он стоит, контент не выдаётся и не заменяется (`document_state_pending`). |
