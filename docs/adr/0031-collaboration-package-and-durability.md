# 0031 — Collaboration package boundary

Status: accepted; protocol-neutral ownership clarified by PLAN4 D17.

Public documents owns the document aggregate, collaboration access policy, persisted protocol binding, neutral session and typed protocol/drainer contracts. A transport registers its adapter through these contracts; it does not replace the common authorization policy.

Realtime editing is available as a commercial add-on. Its product transport, deployment, credentials and durability decisions are shipped in its private documentation.

See [Collaboration protocols](/extending/collaboration-protocols).
