# План реализации Vaulter

**Корневая папка плана — `plan/`.** В `phases/` находятся карточки работ, в `spec/` — спецификации, в `examples/` — примеры и в `checks/` — исполняемые проверки. Начните с карточки [0.1](phases/00-baseline.md). Она ведёт к исходным файлам, примеру и проверке. Исходная ревизия Vaulter — `b230f6e27`. Пакеты проектируются для чистой установки.

| Поставка | Что в ней работает |
| --- | --- |
| Vaulter для платной FlexCms с открытым кодом | Существующее одиночное редактирование и сохранение документов. У типов общий документ, собственный формат содержимого и один путь контроля версий |
| Закрытые дополнения для FlexCrm и Edufy | Коллаборация добавляет PHP, Hocuspocus и клиент. Отдельный репозиторий Sheets поставляет книги, Vue-редактор и вычислитель. В отдельном репозитории AI размещены общее ядро и адаптеры для текста и книг |
| Агент | Через SDK читает только нужные блоки или ячейки, подготавливает изменение, фиксирует его у владельца и проверяет сохранённый результат. Эти операции доступны при закрытом браузере. Первый исполнитель — Laravel AI, AgenTools подключается пакетом |

Долгосрочный ориентир — офис уровня Univer.ai для документов и книг. Первый сквозной результат — агент по поручению пользователя меняет условие договора или заполняет выбранные строки формулами и возвращает проверяемую квитанцию. Приёмка проходит в изолированных потребителях. Подключение к продуктовым приложениям относится к последующим работам.

## Фазы

Работать по одной задаче. В каждой карточке указаны предшественники, порядок действий, карта файлов и идентификаторы проверок. Зависимости указаны для конкретных задач. Например, перенос типа книги 1.1 и исправление WebSocket 2.1 можно вести параллельно; ни одна из этих задач не требует готового AI.

| Фаза | Сдаваемый результат |
| --- | --- |
| [0. Исходное состояние](phases/00-baseline.md) | Установка из архивов, контрольные сценарии и исходная схема БД |
| [1. Документы](phases/01-documents.md) | Универсальная голова документа и типизированные данные, отдельный пакет книги, чистый базовый редактор |
| [2. Коллаборация](phases/02-collaboration.md) | Два пишущих браузера, подтверждение, рестарт и восстановление поколения |
| [3. Текстовый SDK](phases/03-text-sdk.md) | Адресуемые блоки, API агента, квитанции, исполнители и отдельно доказанная запись в живую комнату |
| [4. Книги](phases/04-sheets.md) | Выбранный профиль движка, закрытый редактор и вычислитель. Для XLSX и CSV предусмотрены независимые проверки при включении |
| [5. SDK для книг](phases/05-sheet-sdk.md) | Запись формул в выбранные строки и измеренная стоимость чтения |
| [6. Дополнения](phases/06-extensions.md) | Независимые возможности совместной книги и ссылки на диапазон в Tiptap |
| [7. Поручение](phases/07-agent-workspace.md) | Согласование P/Q, возобновление задания и проверка внешнего канала на эмуляторе |

Проверки плана, примеров и SQL запускаются из корня Vaulter.

```bash
python3 plan/checks/verify-plan.py
python3 plan/checks/verify-fixtures.py
PG_BIN=/usr/lib/postgresql/18/bin bash plan/checks/schema.sh
```
