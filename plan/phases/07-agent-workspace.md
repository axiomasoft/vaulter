# 7. Жизненный цикл поручения

[Пакеты и состояние задания](../spec/implementation/ai.md) · [Тестовые потребители](../spec/implementation/hosts.md) · [Профиль, решения и возобновление](../spec/host-integrations.md).

### 7.1 Принять решение и продолжить задание

**После** — 3.4, 5.1.

1. В тестовой панели показать инициатора, ресурс, diff и digest P/Q, текущую возможность согласования, состояние задания и квитанцию. Два уполномоченных ревьюера одновременно принимают/отклоняют P. Авторизация решения и авторизация исполнения проверяются раздельно.
2. При принятии закрепить один command_id и событие диспетчеризации; при отклонении не отправлять commit. Отключить браузер между фиксацией и ответом; восстановить состояние по ID задания без повторного применения.
3. Для многошагового поручения сохранить черновик планов и отдельные исходы по ресурсам. Если первый документ изменён, а во втором конфликт, продолжение показывает частичный результат и перечитывает вторую цель.

- **7.1-A** Одно решение P и не более одной записи, Q остаётся ожидающим. Утрата прав до commit исключает изменение, утрата прав до чтения исключает выдачу старого diff.
- **7.1-B** После перезапуска известны инициатор, принятое решение, подтверждённые и оставшиеся шаги. Состояние «принято человеком» различимо с «сохранено владельцем».

### 7.2 Проверить смену исполнителя и канала

**После** — 7.1.

1. В одном тестовом профиле вызвать API в процессе PHP, во втором — из авторизованного клиентского процесса через HTTP. Выдать локальному эмулятору канала идентификатор финального сообщения; отправить промежуточное, финальное, повтор финального, затем переподключение.
2. Выбрать профиль на стороне хоста, сохранить связь внешнего события с исходным заданием. Восстановить состояние по ссылке с текущей проверкой доступа. Показывать только подтверждённый результат.

- **7.2-A** Оба профиля используют один контракт, промежуточная реплика ничего не публикует, финальная и её дубликат дают одно задание. Воспроизведение не требует FlexCms, FlexCrm, Edufy или работающего Loqum.
