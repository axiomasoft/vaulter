# 4. Электронная книга

[Структура репозитория Sheets и граница PHP/Node](../spec/implementation/sheets.md) · [Таблицы и их владельцы](../spec/database/sheets.md) · [Процессы](../spec/implementation/processes.md) · [Корпус книги](../examples/workbook.json).

### 4.1 Выбрать профиль движка

**После** — 0.2.

1. Запустить `bash plan/checks/univer-headless.sh` и `bash plan/checks/sheets-browser/run.sh` на закреплённых версиях. Пройти расчёт, реальный ввод, вставку, завершение процесса и открытие. Повторить тест сохранности обязательных ресурсов.
2. Сравнить Univer OSS (`@univerjs/*`, Apache-2.0 — основной коммерчески чистый движок) с IronCalc (`MIT/Apache-2.0`) для серверных расчётов и обмена. `Handsontable`/`HyperFormula` (коммерческая/GPLv3) допустимы **исключительно как офлайн-ориентир бенчмарка, без включения в production-зависимости** ([лицензионный стоп-кран](../spec/engineering-standards.md#2-постоянные-архитектурные-запреты-стоп-краны-ci)). Glide/RevoGrid относятся к сетке записей; требование полноценной книги проверяется формулами, пересчётом и её сериализацией.
3. Зафиксировать в манифесте профиля engine/plugins/schemaVersion и таблицу разрешённых операций для каждого ресурса. Если кандидат теряет неизвестный ресурс, отклонять запись до сохранения. При дефекте переноса conditional formatting отклонять структурные изменения таких книг.

- **4.1-A** Начальный итог 35, после ввода цены 7 итог 41; после вставки вычисляется `=SUM(Detail!D3:D4)`. После холодного открытия ошибочный кэш 999 помечается неактуальным до подтверждённого пересчёта.
- **4.1-B** Сравнение содержит результаты ввода/clipboard/undo, доступности, большого paste, освобождения памяти при закрытии и сохранения ресурсов. Выбраны версия и допустимый профиль; каждое известное ограничение воспроизводится тестом.

### 4.2 Выпустить пакет одиночной книги

**После** — 1.0, 1.1, 4.1.

1. Использовать общий `AtomicDocumentMutation` у владельца. Если 4.2 выполняется до 3.3, добавить этот порт в Documents здесь и повторно использовать в 3.3. Порядок порта (T → N → Edit → D, повтор callback после 40001/40P01, сначала исход по ключу, потом режим/поколение) взять из образца `plan/examples/reference/atomic-mutation/` (`bash plan/checks/atomic-mutation/run.sh` → код 0). Для книги исход ключа хранится в `v_sheets_commands`, а вызов Node выполняется до `run()`. Установить принадлежащие Sheets миграции и тип. PHP разрешает book по идентификатору узла и текущему праву. Вычислитель получает версионированную команду, входной снимок и опции пересчёта. Браузер и фоновый процесс работают с одним форматом.
2. PHP проверяет версию и атомарно публикует согласованный снимок/manifest, стабильные ID таблицы, строк и колонок, исход команды. Запись через generic PUT для управляемого книжного типа отклоняется. Для крупных книг (порог по умолчанию **> 512 КБ** сериализованного снимка) `WorkbookCodec` автоматически выносит сжатый неизменяемый снимок в CAS/S3 (`vaulter-media` + pin `v_blob_references`) и хранит в `v_document_payloads.content` лёгкий JSON-manifest со ссылкой на `blob_id` (защита WAL PostgreSQL от раздувания на 50-листовых книгах). Внешние байты и pin подготавливаются до публикации ссылки.
3. В локальном Vue-потребителе открыть эти данные из PHP, изменить ячейку, закрыть вкладку и процесс Node; открыть вновь. Проверить timeout, конкурирующую запись и restore. [Полные контрольные условия](../spec/spreadsheets.md)

- **4.2-A** Новый браузер и новый процесс расчёта читают одинаковую книгу, формулы, формат и 41. Повтор команды имеет одну квитанцию. Старая цена из C3 не перезаписывает товар, перемещённый в C3.
- **4.2-B** При падении runtime или неподдерживаемом обязательном ресурсе исходный снимок доступен. Повтор обработки безопасен. При удалении удерживаемая ревизией копия сохраняется до освобождения последней ссылки.

**Образец** → `plan/examples/reference/workbook-operation/` → `packages/runtime/src/protocol.ts` (`src/wire.ts`), `src/operation.ts:runOperation`, `packages/sheets/src/Actions/CommitWorkbookCommand.php` (`php/Owner.php` `WorkbookOwner::commit`, `verifyCandidate`), `src/vue-client.ts:submitWorkbookCommand`; формат — [wire-контракт](../spec/implementation/sheets-runtime-wire.md) → `bash plan/checks/workbook-operation/run.sh` → `PASS` (A0–A8, D1–D3 перебазирование правок ячеек, S1–S7). Образец не заменяет пакетную приёмку `workbook-contract.sh`: PostgreSQL, ACL, HTTP и браузер в нём на границе.

### 4.3 Обмен XLSX и CSV

**После** — 4.2.

Условие запуска — поставка заказывает хотя бы один из форматов XLSX и CSV. В [отчёте](../acceptance.md) записать заказанный набор в `exchange_formats`. Для каждого формата с обменом требуется `pass`. Для оставшегося формата требуется `disabled` со свидетельством отсутствия capability в API. Поставка без обмена пропускает эту задачу.

1. При импорте XLSX сохранить исходный файл в Media. Использовать **только открытые MIT/Apache-2.0 конвертеры** (IronCalc / OOXML в Node; платный `@univerjs-pro/exchange` запрещён). До распаковки архива проверять запрет `..`, ведущих `/`, симлинков `S_IFLNK` во внешних атрибутах ZIP, лимиты числа записей/объёма распаковки (Zip-bomb) и отключение XXE/external relationships ([стандарты](../spec/engineering-standards.md#36-s3-карантин-clamav-instream-cas-аренды-и-безопасность-архивов)). Построить результат с потерями по объектам и листам; публиковать редактируемую книгу только по политике поддерживаемого профиля.
2. Экспортировать определённую версию книги. Повторно открыть в целевом Excel без правки и после вставки строки. Для дат сравнить serial и календарное значение в книгах 1900/1904.
3. Для XLSX сравнить формулы/стили/merged cells/валидацию/именованные диапазоны/условное форматирование и исходный блоб. Для CSV зафиксировать диалект, кодировку, кавычки и правила типов; экспортировать один выбранный лист. Проверить строки с разделителем, переводом строки, ведущими нулями и литералом, начинающимся с «=». Проиграть повтор фонового задания.

- **4.3-A** Для включённого XLSX по каждому обещанному свойству приложены входной XLSX, конкретная версия артефакта, повторный импорт или открытие в Excel и отчёт о потерях. Неизвестная структура не исчезает молча; оригинал доступен по своим правам. При отключённом XLSX проверить отсутствие capability.
- **4.3-B** При включённом CSV эталонные значения и их типы выдерживают повторное открытие в заданном диалекте; формулы и стили других листов не обещаются. При отключённом CSV проверить отсутствие capability.
