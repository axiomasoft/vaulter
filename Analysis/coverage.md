# Карта проходов

Ветка `analysis/latest-stack-and-runs`. Проход — это чтение области и правка, если расхождение не меняет закреплённый ответ клиенту. Смена кода ответа остаётся в `proposals.md`.

| Область | Что сделано в коде | Что только записано |
| --- | --- | --- |
| CI, Laravel 13, Postgres 18, MySQL 9.7 | матрица, один движок на джоб | load-стенд на Postgres 16 |
| Прогоны SQLite | партиции рядом, свой скелет | стена `make test-full` не перемерена |
| core: корреляция, конфиг-списки | один токен, `StringList` | — |
| drive: загрузки, скан, активность, корзина | потолки tus и S3, битый блоб не сканируется, повтор чанка ограничен, восстановление сравнивает id как строки | tus без длины; старый `clean` после починки объекта; повтор purge |
| documents: запись, комментарии, ключи | общий замок, родитель на том же узле, `Identity::fitsKey` | якорь без потолка; `invalid_destination` против `cross_drive_operation` |
| media CAS | обрыв потока не становится дайджестом | — |
| webhooks | пустая ability, строгое сравнение арендатора | усыновление подписки без арендатора |
| collaboration | флаг чекпоинта в `supportsState`. Права хаба, срок токена, read-only append и сверка поколения прочитаны: новой дыры нет | 403 хаба против 409 lifecycle; снятие головы по классам событий |
| filament | пикер не предлагает перенос папки в своё поддерево | — |
| azgard | — | общий гард и пробные роли |
| vue | клиент tus шлёт длину файла и пустой PATCH для нулевого файла; серверный отказ сверх длины его не задевает | сверка полей API ещё идёт |
| outbox | — | окно сверки может перешагнуть незакоммиченный seq |

Открытые проходы этой итерации: Filament (админка целиком), Azgard, клиент Vue, экспорт документов и идемпотентность ядра. Их находки либо становятся коммитом, либо строкой в `proposals.md`.
