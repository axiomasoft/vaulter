## 3. Не проверено / ограничения

- **Расхождение плана с расположением фазового файла (Known Deviation).** Задание и plan.md ссылаются на `plans/AUDIT-VLT/P0.md`, но фактический файл фазы лежит в `plans/AUDIT-VLT/phases/P0.md`. Содержимое item'а P0.1 прочитано из `phases/P0.md`; выдумывания не было (§2 Execution Rules — «файла из Required Reads нет → не импровизировать»). Это расположение, не отсутствие; фиксируется как Known Deviation, эскалации сверх записи не требует.
- **`docs/plan/00-master-plan.md`** прочитан частично (первые ~40 строк — статус-секция и таблица «Сделано»); для инвентаризации этого достаточно (нужен был факт наличия и связи ADR/пакетов). Полный разбор master-plan — не задача P0.1.
- **Число тестов = число test-файлов**, не число `it()/test()`-кейсов. Перекрёстно: `pest --list-tests` перечисляет 347 строк (перечисление без прогона, Implementation Rules P0.1); точное сопоставление кейс↔пакет не строилось (для описи достаточно счётчика файлов).
- **`composer show --direct`** не выполнялся: `composer.lock`/`vendor` в корне могут быть не синхронизированы, а команда с флагом `--direct` при отсутствии установки даёт неполный результат; версии зафиксированы по констрейнтам `composer.json` (require/require-dev), чего достаточно для baseline. Матрица Laravel/Testbench/Filament — предмет P0.2 (T6) и P4.4 (D12), не P0.1.
- **`packages/core` не имеет package-local `phpstan.neon`** — анализируется корневым `phpstan.neon` (`level: max`); это факт конфигурации, не дефект (вердикты — вне P0.1).
- **`packages/vue` без `composer.json`** — TypeScript/Vue-пакет; поля «require php/laravel», «phpstan.neon», «test-файлы (php)» для него неприменимы (n/a).
- Проверено, что дерево read-only чистое: `git status --porcelain -- packages docs e2e hocuspocus-server` → пустой вывод (D2); `plan-lint plans/AUDIT-VLT` → OK, 0 ошибок.
