1. **high** — `packages/drive/src/Actions/UploadFileAction.php:93` (same inversion at `packages/drive/src/Actions/CopyNodeAction.php:65`)
   - **Defect:** On MySQL/MariaDB, `VaulterDatabase::lockTree` locks the `storages` row (`packages/core/src/Database/VaulterDatabase.php:49`). Upload and Copy lock a node row first and only later update that same row in `adjustUsedBytes`. Move and ForceDelete take the storage row first, then the node row.
   - **Failure scenario:** T1 uploads into folder F and locks F. T2 moves into F, locks the storage row, and waits for F. T1’s `adjustUsedBytes` (`UploadFileAction.php:118`) waits for the storage row. InnoDB aborts one transaction with error 1213. The same cycle happens for a file copy (`CopyNodeAction.php:86`) against a move into that folder, and for force-delete of F (`ForceDeleteNodeAction.php:52` holds the storage row, then waits for F) against an upload that already holds F. Laravel retries the whole callback up to 3 times, then the request fails. A retry of upload also re-runs `BlobStore::commit`, whose `promote()` has already written bytes that the rolled-back transaction does not remove.
   - **Fix:** In every transaction that may call `adjustUsedBytes`, call `lockTree($storageId)` before `TreeGuard::lock()`. The storage row is then held before any node lock, and the later quota UPDATE does not take a new lock. Leave PostgreSQL on the advisory lock it already uses.

2. **medium** — `packages/drive/src/Actions/RestoreNodeAction.php:49`
   - **Defect:** The parent id that is locked is taken from the caller’s model after `lockTree`, and `sync()` runs only after that list is built. `resolveDestinationParent` (`RestoreNodeAction.php:90`) then looks up the parent id from the locked row. A miss is treated as “parent gone” and the node is restored to the root. Trash does not take `lockTree`, so a parent that was not locked can still change under this transaction.
   - **Failure scenario:** The caller has N loaded under live folder A (`parent_id=A`, `trashed_from_parent_id=null`). Another request moves N to live folder B and trashes it (`parent_id=B`, `trashed_from_parent_id=B`) and commits. Restore locks `[N, A, root]`. After `sync`, the lookup for B misses (`RestoreNodeAction.php:96`) and N is restored under the root while B is still a live folder.
   - **Fix:** After `lockTree`, lock and `sync` N and the root first. Read `trashed_from_parent_id ?? parent_id` from that row, lock that id, then resolve. A second `lockForUpdate` while `lockTree` is held does not cycle with Move, Restore, or ForceDelete.

3. **medium** — `packages/core/database/migrations/2026_10_01_000006_nodes_cleanup.php:144`

    31	/**
    32	 * Commit an upload into the Drive (§2.4 commit flow): stage → BlobStore.commit
    33	 * (content-addressed dedup) → File + FileVersion(version_no) + version↔blob edge
    34	 * → file node (current_version_id, mime, size, extension).
    35	 *
    36	 * Quota (§1.5 eager): the incoming size is checked against the storage's
    37	 * quota_bytes BEFORE the blob is committed (we never store bytes we must reject),
    38	 * and used_bytes is incremented WITHIN the transaction.
    39	 *
    40	 * Two paths share one Action:
    41	 *   - new file → create Node(kind=file) + File + FileVersion(version_no=1);
    42	 *   - new version (upload onto an existing file node) → bump version_no, repoint
    43	 *     current_version_id, mark the prior head superseded, and adjust used_bytes by
    44	 *     the SIZE DELTA (new size − previous head size), not the full size.
    45	 *
    46	 * Authorization (M2a / H.2) is enforced upstream at the HTTP controller
    47	 * boundary (NodeController + AccessResolver); this Action stays pure.

    63	    public function execute(UploadFileData $data): Node
    64	    {
    65	        return $this->metrics->timing(
    66	            name: 'vaulter_upload_chunk_duration_seconds',
    67	            operation: fn (): Node => $this->executeUpload($data),

    75	    private function executeUpload(UploadFileData $data): Node
    76	    {
    77	        $probedSize = $this->probeSize($data->stream);
    78	        $previousSize = $this->previousHeadSize($data);
    79	
    80	        // Eager quota — the delta a new version adds is (new − old); a brand-new
    81	        // file adds its full size. Checked BEFORE we commit any bytes (§1.5). The
    82	        // probe is best-effort for non-seekable streams; the real used_bytes
    83	        // adjustment below uses the committed blob's authoritative size.
    84	        $this->assertWithinQuota(data: $data, delta: $probedSize - $previousSize);
    85	
    86	        // A new file gets a normalized name under a resolved folder (the root when no
    87	        // destination is given); a new version keeps the node's place and name.
    88	        $name = $data->isNewVersion() ? null : NodeName::normalize($data->resolvedName());
    89	        $parentId = $data->isNewVersion() ? null : $this->tree->destinationId(storage: $data->storage, into: $data->into);
    90	
    91	        return $this->database->transaction(function () use ($data, $previousSize, $name, $parentId): Node {
    92	            $this->tree->lockBeforeQuota($data->storage->id);
    93	
    94	            if ($name !== null && $parentId !== null) {
    95	                $this->assertDestination(data: $data, parentId: $parentId, name: $name);
    96	            }
    97	
    98	            $blob = $this->blobs->commit(
    99	                stream: $data->stream,
   100	                tenantId: $this->tenantId($data),
   101	                storageId: $this->storageIdForScope($data),
   102	                disk: $data->storage->disk,
   103	            );
   104	
   105	            $size = $blob->size_bytes;
   106	
   107	            $this->metrics->counter(
   108	                name: 'vaulter_upload_bytes_total',
   109	                amount: $size,
   110	                labels: ['protocol' => 'single'],
   111	            );
   112	
   113	            $node = $name === null || $parentId === null
   114	                ? $this->commitNewVersion(data: $data, blob: $blob, size: $size)
   115	                : $this->commitNewFile(data: $data, blob: $blob, size: $size, name: $name, parentId: $parentId);
   116	
   117	            $delta = $size - $previousSize;
   118	
   119	            if ($delta !== 0) {
   120	                $this->storageStore->adjustUsedBytes(storage: $data->storage, delta: $delta);
   121	            }
   122	
   123	            return $node;
   124	        });
   125	    }

   127	    /**
   128	     * New-file path (§2.4): node(kind=file) → file → version_no=1 → edge → repoint.
   129	     */
   130	    private function commitNewFile(UploadFileData $data, Blob $blob, int $size, string $name, int|string $parentId): Node
   131	    {
   132	        $node = $this->nodeStore->create([
   133	            'storage_id' => $data->storage->id,
   134	            'parent_id' => $parentId,
   135	            'kind' => NodeKind::File,
   136	            'name' => $name,
   137	            'mime_type' => $data->mimeType,
   138	            'extension' => $this->extension($data->originalName),
   139	            'size_bytes' => $size,
   140	            'owner_id' => $data->actorId,
   141	            'created_by' => $data->actorId,
   142	        ]);
   143	
   144	        $file = $this->files->create([
   145	            'node_id' => $node->id,
   146	            'mime_type' => $data->mimeType,
   147	            'size_bytes' => $size,
   148	            'version_count' => 0,
   149	        ]);
   150	
   151	        $version = $this->makeVersion(data: $data, file: $file, blob: $blob, size: $size, versionNo: 1);
   152	
   153	        $this->blobs->attach($version, $blob);
   154	
   155	        $this->files->repointHead(
   156	            file: $file,
   157	            currentVersionId: $version->id,
   158	            mimeType: $data->mimeType,
   159	            sizeBytes: $size,
   160	        );

   163	            'file_id' => $file->id,
   164	            'current_version_id' => $version->id,
   165	        ]);

   170	    }

   172	    /**

   174	     * (deduped) blob, mark the prior head superseded, repoint file + node heads.
   175	     */
   176	    private function commitNewVersion(UploadFileData $data, Blob $blob, int $size): Node
   177	    {
   178	        $node = $data->targetNode;
   179	
   180	        if (!$node instanceof Node) {
   181	            // Defensive: isNewVersion() already guaranteed this; keeps PHPStan honest.
   182	            throw new LogicException('[Vaulter] A new-version upload requires a target node.');
   183	        }
   184	
   185	        /** @var File $file */
   186	        $file = $node->file()->firstOrFail();
   187	
   188	        $previousHead = $file->currentVersion()->first();
   189	
   190	        $version = $this->makeVersion(
   191	            data: $data,
   192	            file: $file,
   193	            blob: $blob,
   194	            size: $size,
   195	            versionNo: $this->versions->nextVersionNo($file),
   196	        );
   197	
   198	        $this->blobs->attach($version, $blob);
   199	
   200	        if ($previousHead instanceof FileVersion) {
   201	            $this->versions->markSuperseded($previousHead);
   202	        }
   203	
   204	        $this->files->repointHead(
   205	            file: $file,
   206	            currentVersionId: $version->id,
   207	            mimeType: $data->mimeType ?? $file->mime_type,
   208	            sizeBytes: $size,
   209	        );
   210	
   211	        $this->nodeStore->repointHead(
   212	            node: $node,
   213	            currentVersionId: $version->id,
   214	            mimeType: $data->mimeType ?? $node->mime_type,
   215	            extension: $node->extension,
   216	            sizeBytes: $size,
   217	        );
   218	
   219	        event(new NodeVersionCommitted(
   220	            node: $node->refresh(),
   221	            file: $file,
   222	            version: $version,
   223	            versionNo: $version->version_no,
   224	            actorId: $data->actorId,
   225	        ));
   226	
   227	        return $node;
   228	    }

   251	    /**
   252	     * Reject the upload BEFORE committing bytes when it would push used_bytes past
   253	     * quota_bytes (§1.5). A null quota is unlimited; a non-positive delta (a
   254	     * smaller new version) never trips the check.
   255	     */
   256	    private function assertWithinQuota(UploadFileData $data, int $delta): void
   257	    {
   258	        $quota = $data->storage->quota_bytes;
   259	
   260	        if ($quota === null || $delta <= 0) {
   261	            return;
   262	        }
   263	
   264	        if ($data->storage->used_bytes + $delta > $quota) {
   265	            throw QuotaExceededException::forStorage(
   266	                storageId: $data->storage->id,
   267	                quotaBytes: $quota,
   268	                usedBytes: $data->storage->used_bytes,
   269	                incomingBytes: $delta,
   270	            );
   271	        }
   272	    }

   274	    /**
   275	     * The destination folder is locked before the bytes are committed, so it cannot
   276	     * be trashed or replaced by a file between the check and the insert.
   277	     */
   278	    private function assertDestination(UploadFileData $data, int|string $parentId, string $name): void
   279	    {
   280	        $parent = $this->tree->locked($this->tree->lock([$parentId]), $parentId);
   281	        if (!$this->tree->sameStorage($parent, $data->storage->id)) {
   282	            throw CrossStorageMoveException::between(fromStorageId: $data->storage->id, toStorageId: $parent->storage_id);
   283	        }
   284	
   285	        $this->tree->assertActiveFolder($parent);
   286	
   287	        if ($this->nodeRead->siblingNameExists(storage: $data->storage, parentId: $parentId, name: $name)) {
   288	            throw NodeNameConflictException::forName(name: $name, parentId: $parentId);
   289	        }
   290	    }

    23	 * the row locks on the node and its destination:

    72	            }

    92	     * never a recursive correlated aggregate in the request path.

    95	    {
    96	        if (Identity::stringify($into->id) === Identity::stringify($node->id)) {
    97	            throw CycleException::forMove(nodeId: $node->id, intoId: $into->id);
    98	        }
    99	
   100	        $descendantIds = array_map(
   101	            Identity::stringify(...),
   102	            $this->nodes->subtree($node)->modelKeys(),
   103	        );
   104	
   105	        $this->metrics->histogram(
   106	            name: 'vaulter_subtree_nodes_touched',
   107	            value: count($descendantIds),
   108	            labels: ['operation' => 'subtree_mutate'],
   109	        );
   110	
   111	        if (in_array(Identity::stringify($into->id), $descendantIds, strict: true)) {
   112	            throw CycleException::forMove(nodeId: $node->id, intoId: $into->id);
   113	        }
   114	    }
   115

   118	        $exists = $this->nodes->siblingNameExists(

   121	            name: $node->name,
   122	            ignoreId: $node->id,
   123	        );
   124

   126	            throw NodeNameConflictException::forName(name: $node->name, parentId: $into->id);
   127	        }

    22	 * Permanently soft-delete a trashed node and its subtree (§2.10 stage 2). Only a
    23	 * node already in the trash qualifies (a live node goes through the trash first)
    24	 * and the root never does; the subtree is read under the storage tree lock. The
    25	 * order matters and is the GC contract (§2.3 / §2.4):
    26	 *   1. detach every version↔blob edge in the subtree — the edge IS the liveness
    27	 *      truth (H.3), so dropping it makes the blob GC-eligible; the bytes are
    28	 *      NEVER deleted here (M1b's two-phase GC reclaims them);
    29	 *   2. soft-delete (deleted_at) the node rows in one bulk UPDATE;
    30	 *   3. decrement used_bytes by the freed LIVE size (§1.5 — trash kept the bytes;
    31	 *      forceDelete is where the quota is actually reclaimed).
    32	 *
    33	 * Authorization (M2a / H.2) is enforced upstream at the HTTP controller
    34	 * boundary (NodeController + AccessResolver); this Action stays pure.
    35	 */
    36	final readonly class ForceDeleteNodeAction
    37	{
    38	    public function __construct(
    39	        private NodeReadRepository $nodes,
    40	        private NodeStoreRepository $store,
    41	        private StorageStoreRepository $storageStore,
    42	        private BlobStore $blobs,
    43	        private VaulterDatabase $database,
    44	        private TreeGuard $tree,
    45	    ) {}
    46	
    47	    public function execute(Node $node, int|string|null $actorId = null): void
    48	    {
    49	        $storage = $node->storage;
    50	
    51	        $this->database->transaction(function () use ($node, $storage, $actorId): void {
    52	            $this->database->lockTree($node->storage_id);
    53	
    54	            $current = $this->tree->sync($node, $this->tree->locked($this->tree->lock([$node->id]), $node->id));
    55	
    56	            $this->tree->assertNotRoot(node: $current, operation: 'delete');
    57	
    58	            if ($current->trashed_at === null) {
    59	                throw NodeNotTrashedException::forNode($current);
    60	            }
    61	
    62	            $subtree = $this->nodes->subtree($current);
    63	            $ids = $subtree->modelKeys();
    64	            $freedBytes = 0;
    65	
    66	            foreach ($subtree as $member) {
    67	                if ($member->kind !== NodeKind::File) {
    68	                    continue;
    69	                }
    70	
    71	                $freedBytes += $this->detachFilePayload($member);
    72	            }
    73	
    74	            $this->store->softDeleteSubtree(collect($ids));
    75	
    76	            if ($freedBytes > 0) {
    77	                $this->storageStore->adjustUsedBytes(storage: $storage, delta: -$freedBytes);
    78	            }
    79	
    80	            event(new NodeForceDeleted(
    81	                storageId: $current->storage_id,
    82	                nodeIds: array_values($ids),
    83	                freedBytes: $freedBytes,

    85	            ));
    86	        });
    87	    }
    88	
    89	    /**
    90	     * Detach every blob edge of every version of a file node and return its live
    91	     * head size (the bytes the storage stops accounting for). Detaching only drops
    92	     * the reference — the physical object is reclaimed later by GC.
    93	     */
    94	    private function detachFilePayload(Node $node): int
    95	    {
    96	        /** @var File|null $file */
    97	        $file = $node->file()->first();
    98	
    99	        if (!$file instanceof File) {
   100	            return 0;
   101	        }
   102	
   103	        foreach ($file->versions()->get() as $version) {
   104	            $this->detachVersionEdges($version);
   105	        }
   106	
   107	        return $node->size_bytes;
   108	    }
   109	
   110	    private function detachVersionEdges(FileVersion $version): void

   112	        foreach ($version->blobs as $blob) {
   113	            /** @var FileVersionBlob $pivot */
   114	            $pivot = $blob->getRelationValue('pivot');
   115	
   116	            $this->blobs->detach(
   117	                version: $version,
   118	                blob: $blob,
   119	                role: $pivot->role,
   120	                ordinal: $pivot->ordinal,
   121	            );
   122	        }
   123	    }

## Current PanelTablesBuilder::addSingleRootIndex
     * Only the drive root may have no parent (one per storage). Without it a node
     * written with a NULL parent becomes a second root that the root listing never
     * shows, and sibling-unique cannot catch duplicates because NULL parents differ.
     *
     *  - PostgreSQL / SQLite: a PARTIAL unique index on (storage_id) WHERE parent_id IS NULL.
     *  - MySQL/MariaDB: a stored generated column carries storage_id only for a
     *    parentless row (NULL otherwise, exempt from UNIQUE) under a plain unique index.
     *
     * Public so the upgrade migration adds the same index to an existing table.
     */
    public function addSingleRootIndex(string $table): void
    {
        $driver = $this->schemaConnection()->getConnection()->getDriverName();
        $name = "{$table}_root_uniq";

        if ($driver === 'pgsql' || $driver === 'sqlite') {
            $this->dbConnection()->statement(
                "CREATE UNIQUE INDEX {$name} ON {$table} (storage_id) WHERE parent_id IS NULL",
            );

            return;
        }

        if ($driver === 'mysql' || $driver === 'mariadb') {
            // Two auto-committing DDL statements: each step is skipped when already
            // applied, so an upgrade interrupted between them can simply be re-run.
            if (!$this->schemaConnection()->hasColumn($table, 'root_storage')) {
                $this->dbConnection()->statement(
                    "ALTER TABLE `{$table}` ADD COLUMN `root_storage` VARCHAR(64) ".
                    'GENERATED ALWAYS AS (CASE WHEN `parent_id` IS NULL THEN `storage_id` ELSE NULL END) STORED',
                );
            }

            if (!$this->schemaConnection()->hasIndex($table, $name)) {
                $this->dbConnection()->statement("ALTER TABLE `{$table}` ADD UNIQUE INDEX `{$name}` (`root_storage`)");
            }
        }
    }
