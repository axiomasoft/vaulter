### P5.2 — Product fixtures и матрица lock/pool/tree/sweeper

**Intent:** Добавить disposable fixtures и реальные Vaulter scenarios для upload-session, CAS,
tree move, collab issuance и live-PATCH-vs-sweeper, включая детерминированную пару разных payload с
одинаковым `hashtext(scope|sha256)`.
**Why:** Raw advisory-lock SQL доказывает примитив, но не доказывает маршруты, integrity или
фактическую цену PHP/FPM. Нужны отдельные same/different resource controls и post-run invariants.
**Scope Included:** fixture command/manifest/cleanup; same/different tus and S3 sessions; normal and
int4-collision CAS payload pair; 1k-node disjoint/overlapping move fixtures; collab token burst;
expired/live sessions; tier-S 20k and targeted 1m dirty manifests; k6 product scenarios; direct-SQL
pool controls; exact expected-status/integrity matrix; contract tests.
**Scope Excluded:** live authoritative run; full tier-L seed/claim; multi-GiB payloads; correctness
replacement for package concurrency tests; L-02/L-06/L-07 fixes; `packages/*/src`; chaos/network
faults (P7); queue/outbox backlog semantics (P6).

**Implementation Rules:** Fixture generation is idempotent by `fixture_id` and cleanup is exact-id/
disposable-snapshot scoped. Collision search generates bounded small payload candidates, hashes real
bytes, asks PostgreSQL 16 for `hashtext(scope|sha256)`, requires distinct sha256 with equal int4 key,
and fails after 250k candidates instead of fabricating a pair. Manifest re-verifies both SHA and DB
hash before run. Same-resource storm expects one progress owner plus protocol conflicts and is never
checked against normal ≤5 % budget; different-resource profile is. CAS collision and normal controls
must end with both distinct blobs/bytes intact. Tree cases restore fixture state per repetition and
verify parent/cycle/node counts. Dirty 1m manifest is a targeted cardinality probe, not tier L.
**Code Guidance:** Use small bounded request bodies; P4 owns multi-GiB memory. k6 barrier skew and
actor mapping are explicit; no `sleep()`-only synchronization. Do not label direct SQL as OP/SLO.
Colliding CAS payloads test false serialization, not hash collision in SHA-256. Sweeper overlap uses
the real Artisan command and real PATCH while preserving exact before/after session/staged-byte
invariants. Never weaken SLO or catch 5xx as success merely because current code is expected RED.
**Validation:** load Pest tests prove deterministic/idempotent fixture manifests, collision equality,
distinct payload SHA, exact cleanup and dirty-count profiles; `k6 inspect` succeeds; static case
validator enumerates every required surface × shape × admitted N and classifies expected 409s;
S0 contract run exercises one lightweight cell per surface without 1m seed; post-run checks detect
blob aliasing, torn upload, tree cycle/lost node and swept live session.
**Deliverables:** reproducible fixtures, exact case matrix, product k6 scenarios, primitive pool
controls, integrity validators and safe cleanup.
