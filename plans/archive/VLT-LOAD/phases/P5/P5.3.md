### P5.3 — Авторитетный tier-S concurrency и dirty-sweeper run

**Intent:** Выполнить одну immutable run family: tier-S product matrix, N=200/201 SQL/pool controls,
tier-S sweeper repeats и один isolated 1m expired-session probe.
**Why:** Только одновременный product traffic и server-side snapshots показывают, где возникает
очередь/конфликт и сохраняются ли integrity/error budgets; synthetic fixtures этого не доказывают.
**Scope Included:** D41/P8 live preflight; run/dataset/image/config fingerprint; matrix execution;
три valid repeats product-realistic cells; same-resource stress; PG/PgBouncer sampling; logs/deadlock
deltas; Prometheus/k6 capture; 20k sweeper ×3; 1m targeted probe ×1; rejected attempts; post-run
integrity; machine-readable cell verdicts.
**Scope Excluded:** production/shared systems; tier M/L performance claims; package fixes; network/
S3 chaos; queue semantics; changing pool/SLO after results; deleting rejected evidence.

**Implementation Rules:** One `run_id` binds all sources. Preflight fixes git SHA, dataset/snapshot,
image digests, Postgres/PgBouncer settings, counters/log cursor, clock source and P8 series. Matrix
order is lightweight controls → tier-S realistic → same-resource stress → pool boundary → 20k sweep
→ restored snapshot → 1m probe, so harness failure appears before destructive/expensive cells.
Product-realistic cells need three successful repetitions; stress/timeout/1m controls need one valid
attempt and cannot fill a missing realistic repeat. Infrastructure failure stays rejected with cause.
Every destructive cell restores a verified disposable snapshot. OOM/restart, timeout, counter reset,
missing log range, barrier skew, integrity failure or cross-run metric is typed product-red vs
evidence-invalid; neither is silently retried over.
**Code Guidance:** Polling must not perturb pool under test: collectors use reserved/admin/direct
connections declared in manifest. The configured 120s PgBouncer `query_wait_timeout` may use one
bounded >120s control; a shorter override is a mechanism-only cell and cannot claim envelope
behavior. Report FPM queue, pool queue and DB lock wait independently. Worst-case 409 ratio is
descriptive; normal different-session ratio alone consumes §0.4 budget. SLO may be RED while raw
evidence remains valid.
**Validation:** `TIER=S ./load/scripts/p5-concurrency.sh run --matrix`; then `verify --run-id <id>`
confirms all manifest cells, exact repetition policy, `N` axes including 200/201, before/after
deadlock/log cursors, PG/PgBouncer/k6/Prometheus links, post-run integrity, 20k ×3 and 1m ×1 sweep
evidence; byte-stable second verify; secret scan empty; restored fixture counts/checksums match.
**Deliverables:** immutable tier-S run family with complete product/lock/pool/sweeper evidence and
machine-readable verdicts, including valid RED outcomes.
