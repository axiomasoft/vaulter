### P7.2 — Isolated injectors, fixtures и degradation matrix

**Intent:** Добавить reversible S3/TCP/PG/ENOSPC injectors, disposable fixtures и точную матрицу
операций/барьеров/ожидаемых инвариантов.
**Why:** Toxiproxy не синтезирует S3 503 и не выполняет PG promotion, а заполнение общего `/tmp` или
kill единственного Postgres небезопасны и дают неверную fidelity.
**Scope Included:** compose chaos overlay; pinned Toxiproxy; transparent MinIO/PgBouncer proxies;
load-only S3 503 controller; two-node PostgreSQL 16 physical-replication lab with explicit fencing,
promotion and PgBouncer repoint; dedicated app tmpfs/TMPDIR ENOSPC lane; deterministic upload/CAS/
outbox fixtures; arm/observe/revert/self-test; fault matrix and isolation guards.
**Scope Excluded:** automatic HA product choice; AWS control-plane/DNS/TLS fidelity; true AWS
multipart UploadId; production/shared systems; package behavior changes; destructive host disk fill.

**Implementation Rules:** Fault API binds run id and rejects foreign/non-chaos targets. S3 proxy
distinguishes pre-upstream 503 from TCP latency/timeout/reset and logs no signed headers/body.
Promotion requires confirmed standby replay position, old-primary fencing before writable routing,
and no automatic failback. ENOSPC uses a dedicated tmpfs and records free bytes plus actual write
length; recovery remounts/restores only that volume. Every injector has idempotent revert and self-test.
**Code Guidance:** Route all tested dependency traffic through declared proxies; direct bypass fails
preflight. Keep network-loss and real promotion cells separate. Current proxied multipart cleans
Flysystem part keys, not AWS UploadId. Use barriers/hooks owned by load harness, not sleeps or product
debug branches. Fixture cleanup is run-prefix/snapshot scoped.
**Validation:** compose config with base+overlay; Python/shell static tests; load Pest proves fixture
idempotency/exact cleanup; S0 contract runs one 503, one TCP reset, one backend termination and one
ENOSPC cell, each with verified revert; promotion rehearsal proves one writable primary and PgBouncer
reconnect; guards reject shared endpoints, unfenced promotion and tmpfs path escape.
**Deliverables:** isolated chaos topology, reversible injectors, safe fixtures and complete fidelity-
labelled degradation matrix.
