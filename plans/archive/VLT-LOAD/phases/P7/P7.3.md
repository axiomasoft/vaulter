### P7.3 — Авторитетный tier-S fault/recovery run

**Intent:** Выполнить одну immutable tier-S run family по object-storage, DB failover/connection loss
и temp ENOSPC с обязательным rollback и post-fault reconciliation.
**Why:** Только реальные HTTP/Artisan paths на MinIO, PostgreSQL/PgBouncer и bounded temp показывают
ambiguous outcomes, lock release, resume/idempotency и фактические orphan/corruption последствия.
**Scope Included:** D41/P8 preflight; image/config/dataset/injector fingerprints; clean baselines;
tus/S3/CAS/abort/sweep S3 cells; upload-commit/outbox/lock-holder connection-loss cells; controlled
primary promotion; spill/CAS-stage ENOSPC cells; fault rollback; readiness/metrics/log/DB/object/temp/
queue capture; checksums and machine verdicts; retained rejected attempts.
**Scope Excluded:** production/shared systems; automatic HA recommendation; AWS-specific fidelity;
tier M/L claims; package fixes; changing matrix/thresholds after observing results.

**Implementation Rules:** One run id binds every plane. Preflight freezes SHA, images, client retry/
timeout config, PgBouncer mode, WAL/replay positions, MinIO prefix, tmpfs size and clocks. Correctness
cells run three repetitions; mechanism/promotion controls run once after clean restore. Injector arm
requires barrier ACK. Every cell reaches reverted+reconciled or is evidence-invalid; timeout/restart,
partial evidence, split-brain, cleanup failure or checksum mismatch is never silently retried over.
**Code Guidance:** Fence first, promote second, route third. Preserve ambiguous attempts and reconcile
by session/event/blob identity before retry. Verify both DB→object and object→DB directions plus staged
and part prefixes. A valid RED product verdict may still complete measurement work.
**Validation:** `TIER=S ./load/scripts/p7-chaos.sh run --matrix`; `verify --run-id <id>` proves exact
cells/repetitions, barrier/fault/revert order, one writable PG primary, lock release, retry/resume state,
DB/object/checksum joins, zero cross-run resources and full cleanup; byte-stable second verify; secret
scan empty; base snapshot counts/checksums restored.
**Deliverables:** immutable tier-S fault/recovery run family with complete typed evidence and GREEN,
RED or evidence-invalid verdict for every declared cell.
