### P7.1 — Chaos lane, phase ledger и evidence validator

**Intent:** Построить run-scoped orchestration lane, который ставит fault только на подтверждённом
barrier и доказывает rollback, recovery и reconciliation по полным evidence carriers.
**Why:** Container kill или один 5xx без точного момента, fidelity и post-fault state не показывает,
какая запись была принята, откатилась ли транзакция и остались ли повреждённые/осиротевшие bytes.
**Scope Included:** run/cell/attempt manifest; baseline/armed/fault/revert/recovery/reconcile ledger;
barrier protocol; injector event schema; DB/MinIO/temp/readiness/Prometheus collectors; checksum/state
reconciler; validator; positive/truncated/cross-run/missing-revert/ambiguous-outcome fixtures;
dry-run/run/revert/verify CLI; signal-safe emergency revert.
**Scope Excluded:** injectors/topology; product fixtures; authoritative run; package fixes;
production endpoints; invented recovery thresholds.

**Implementation Rules:** Closed plane enum is `product-realistic`, `transport-control`,
`protocol-control`, `primary-transition`, `storage-control`. Every event binds run/cell/attempt,
fault id, injector version/config digest, target, direction, monotonic/wall time and phase. `armed`
requires observed barrier; `recovered` requires successful dependency probe plus product reconcile.
Missing revert/terminal marker/checksum is evidence-invalid. Artifacts publish atomically after verify.
**Code Guidance:** Keep dependency availability, HTTP outcome and durable product state separate.
Record object key/checksum/size, never object body or credentials. Persist rejected attempts. Cleanup
is exact run scope; never wildcard bucket/database/volume deletion. Report timing without RTO verdict.
**Validation:** `sh -n` scripts; `python3 -m unittest load/gates/test_p7_chaos.py`; validator accepts
complete fixture and rejects missing barrier/revert, overlapping fault ids, impossible phase order,
cross-run object, absent checksum and unresolved ambiguity; `TIER=S ./load/scripts/p7-chaos.sh dry-run`
emits the exact matrix without Docker/DB/object mutations; interrupt fixture proves revert execution.
**Deliverables:** chaos orchestration lane, typed phase/injector/evidence schema, reconciler, negative
fixtures and documented dry-run/revert/verify workflow.
