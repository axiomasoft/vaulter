### P8.9 — Optional tracing seam и selected package spans

**Intent:** Реализовать SDK-neutral `TraceRecorder` с Null/Fake и только те package spans, которые
P8.8 выбрал из frozen allowlist.
**Why:** Reusable packages не должны зависеть от OpenTelemetry SDK/exporter, а выбранные hotspots
должны сохранять единый parent/child и error contract без изменения business behavior.
**Scope Included:** public TraceRecorder contract; Null/Fake; DI/config; selected controller/action/
repository/background spans; bounded attributes; propagation through current active context;
package tests; explicit no-op branch.
**Scope Excluded:** host SDK/exporter; Collector/Tempo/Jaeger; raw entity identifiers; async context
serialization; unselected spans; deferred metrics.

**Implementation Rules:** Before editing, resolve P8.8 terminal readiness and manifest digest through
the Task readiness API; missing/corrupt readiness is `dependency-not-ready`. API carries no OTel
types. Public contract is exactly
`span(string $name, callable $operation, array $attributes = []): mixed`; PHPDoc preserves callback
result type and restricts attributes to the closed scalar vocabulary in §20.3. No public
`startSpan`/`endSpan` or context object is exposed. Null executes callbacks directly without clock,
allocation, I/O or context mutation. Enabled adapter owns current context; nested selected boundaries
form parent/child in call order. Incoming HTTP extraction/server span remains host-owned; package
spans attach to the active span or become an internal root when none exists. Background commands/jobs
start a root unless invoked inside an active context; no trace context is persisted into DB/queue in
this item. Exceptions propagate unchanged; escaped exceptions set ERROR with bounded `error.type`,
while expected conflict/validation outcomes remain non-error attributes. Only §20 attributes are
allowed. `mode=no-op` creates no package tracing symbols or source diff and instead proves absence in
the finding.
**Code Guidance:** Span wrappers must not add branches to business decisions, transactions, retries
or streams. Names come from the closed target registry and never include IDs. No raw UUID, tenant,
user, email, token, filename, SQL, URL, exception class/message/stack or arbitrary text. Optional
correlation uses only the bounded run-scoped surrogate contract in §20.
**Validation:** selected packages' focused Pest tests assert exact span names, nesting, attributes,
exception propagation and no duplicate layer; package PHPStan max and Pint; public API snapshot,
including the exact `span()` signature; Composer/package compile without any `open-telemetry/*` dependency; static
scan rejects forbidden attributes/OTel types. For `mode=no-op`, validator proves no tracing classes,
config keys or source changes and the finding records the D41 branch.
**Deliverables:** SDK-neutral tracing seam, selected package spans and Fake tests, or a verified D41
no-op finding when P8.8 emitted an empty target set. Terminal evidence records the exact consumed
P8.8 manifest digest for P8.10/P8.11 reconciliation.
