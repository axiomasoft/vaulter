### P8.1 — Исполнимая спека наблюдаемости и публичный контракт `MetricsRecorder`

**Intent:** Создать `plans/VLT-LOAD/observability-spec.md` — единственный исполнимый контракт для P8.2–P8.7:
точная PHP-сигнатура `MetricsRecorder`; семантика Null/Fake/host adapter; реестр всех 50 metric families
из `slo-gates.md` §5.1–§5.3; ownership, anchor, cardinality и overhead policy; граница `/up`/`/ready`.

**Why:** В §5 находится 50 уникальных имён в 40 строках (12/10/28), а прежнее число 37 оставляло 13
families вне проверки. Публичная форма recorder'а — SemVer-обязательство, а не локальная деталь трёх
параллельных items. Без одного реестра невозможно честно доказать parity и владение метриками.

**Scope Included:** отдельная строка спеки на каждую из 50 metric families с type, labels, owner
(`package|host|harness`), текущим `file:line` + symbol либо будущим path + symbol + owning item; точная
сигнатура и поведение четырёх методов; bounded-cardinality policy; Null/enabled/overhead semantics;
health ownership и негативные критерии готовности; таблица 12/10/28 и машинная проверка 50/50.

**Scope Excluded:** код в `packages/*` или `load/`; реализация P8.2–P8.7; traces P8.8; реальный
OTel/Prometheus backend; изменение имён, типов или labels §5; исправление измеряемых bottlenecks.

**Inputs:** `plans/VLT-LOAD/slo-gates.md` §5.1–§5.5 · `plans/VLT-LOAD/plan.md` §1.2/§1.3 ·
`plans/VLT-LOAD/findings/P8-rag-otel-health.md` · D31 (аддитивность), D35 (контракт/реестр),
D36 (health ownership) · `packages/core/src/Contracts/Access/AzgardGuard.php` ·
`packages/core/src/Testing/FakeAzgardGuard.php`.

**Files:** `plans/VLT-LOAD/observability-spec.md` (новый; единственный продукт item).

**Required Reads:**
(1) `plans/VLT-LOAD/slo-gates.md` §5.1–§5.5;
(2) `packages/core/src/Contracts/Access/AzgardGuard.php`;

**Implementation Rules:** Зафиксировать дословно:
`counter(string $name, int|float $amount = 1, array $labels = []): void`,
`gauge(string $name, int|float $value, array $labels = []): void`,
`histogram(string $name, int|float $value, array $labels = []): void`,
`timing(string $name, callable $operation, array $labels = []): mixed`.
`timing()` пишет histogram в секундах, возвращает значение callback и без изменения пробрасывает его
исключение; Null выполняет callback, но не пишет эмиссию. В сигнатуре нет OTel/Prometheus типов, facade
или service locator. `enabled=false` выбирает Null в DI; seam-код не ветвится по config. Ошибка backend'а
не меняет бизнес-результат. `gauge()` принимает абсолютное наблюдаемое значение, не delta; `+1/-1`
запрещено выдавать за gauge. P8-minimum metrics не семплируются; агрегацией владеет backend.

Labels — только bounded strings с нормализованным bool `true|false`; запрещены raw URL, ID/UUID,
user/tenant/email и exception message. Имя/type/labels берутся дословно из §5. Строки с несколькими
именами разворачиваются в отдельные families. `/up` — только Laravel-native process liveness; `/ready`
принадлежит `load/`, проверяет DB/S3/queue и отвечает 200/503 (D36).

**Code Guidance:** Применить `architect:observability-design` и `php:dependency-injection`. Для
существующего seam указать проверенный class/method и текущий `file:line`; для
ещё не существующего — будущий path + symbol + owning P8 item. Нельзя придумывать package anchor для
host/harness-owned signals (`collab_room_active`, process/queue health, внешние RSS/PG observations):
owner должен быть честным, а consumer и способ получения — явными. Перед фиксацией каждого текущего
anchor сверить код и ближайшие тесты. P8.2 заблокирован до независимого GREEN design-review результата
`plans/VLT-LOAD/findings/P8.1-design-review.md`.

**Validation:** `observability-spec.md` существует; извлечённый из §5 список имеет 50 уникальных имён,
а спека — ровно те же 50 без дыр/лишних (12/10/28); у каждой строки заполнены type, labels, owner,
anchor/symbol и owning item; контракт не содержит `OpenTelemetry\*`/`Prometheus\*`; проверка запрещённых
high-cardinality labels и sampling policy явная; health-раздел содержит три независимых negative cases;
`plan-lint.py plans/VLT-LOAD` не получает новых ERROR.
