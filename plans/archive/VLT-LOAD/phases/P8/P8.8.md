### P8.8 — Выбор tracing targets и conditional deferred metrics

**Intent:** Из валидных P3–P7 reports выбрать bounded target set из заранее замороженной allowlist и
выпустить digest-bound `producer-readiness/v1` для P8.9–P8.11.
**Why:** Instrumentation до измерений создаёт overhead на предполагаемых путях; свободный выбор после
результатов позволил бы post-hoc изменить scope или SLO. Нужен один детерминированный reducer,
который допускает и честный no-op.
**Scope Included:** target/metric selection validator; P3–P7 evidence links; ranking по observed
impact; максимум шесть trace targets; условия `blob_dedup_hit_total`/`webhook_dlq_total`; immutable
manifest, finding и producer readiness.
**Scope Excluded:** package/host tracing code; новые SLO; переинтерпретация RED; внешнее исследование;
Collector/Tempo/Jaeger; произвольный target вне `observability-spec.md` §20 allowlist.

**Implementation Rules:** Select only targets with valid observed hotspot/debt evidence and exact raw
IDs; inferred-only candidates are rejected. Exact reducer is frozen in `observability-spec.md`
§20.2: one authoritative score row per target, closed rank enums, integer `impact_ppm`, stable
evidence-id reduction and final target-id tie-break. Validator rejects missing windows/units and
cross-report ambiguity before selection. At most six targets. No confirmed target produces
`mode=no-op` and an empty set, explicitly
accepted by D41. `blob_dedup_hit_total` is enabled only by valid P5 evidence that dedup incidence is
needed to interpret L-07; `webhook_dlq_total` only by valid P6 evidence that adopts a terminal-dead
measurement obligation. Neither condition creates an SLO. Terminal evidence carries exactly one
`producer-readiness/v1` record bound to manifest/spec/report digests; empty is valid under D41.
**Code Guidance:** Preserve product RED separately from execution GREEN. Do not select a target
because it is easy to instrument. A report limitation or evidence-invalid cell cannot select a
target. The finding explains exclusions and no-op just as precisely as inclusions.
**Validation:** `python3 -m unittest load/gates/test_p8_trace_targets.py`;
`python3 load/gates/p8_trace_targets.py verify --manifest plans/VLT-LOAD/artifacts/P8/tracing-targets.json`;
all evidence IDs resolve; target set is unique, allowlisted and ≤6; conditional metric booleans have
the required P5/P6 evidence or are false; repeated verify is byte-stable; producer readiness digest
matches the exact manifest and source reports.
**Deliverables:** validated tracing target manifest, selection/exclusion finding and digest-bound
readiness. `observability-spec.md` §20 remains an immutable frozen input and is not rewritten by
P8.8. `producer-readiness/v1`: consumer=P8.9; modes=nonempty-candidates|empty-by-decision. P8.10
consumes P8.8 terminal state and its recorded manifest digest as ordinary producer evidence; P8.11
resolves that same digest through terminal P8.9/P8.10 evidence.
