### P8.10 — Conditional deferred metrics

**Intent:** Добавить `vaulter_blob_dedup_hit_total` и/или `vaulter_webhook_dlq_total` только когда
P8.8 manifest доказал соответствующее заранее заданное условие.
**Why:** Эти metrics полезны для интерпретации P5/P6, но не входят в принятые SLO; без condition gate
они стали бы post-hoc cardinality/telemetry scope.
**Scope Included:** enabled family registry rows, additive emission at exact dedup/dead transitions,
Fake tests, finding с enabled/disabled verdict; deterministic no-op для каждой false condition.
**Scope Excluded:** новые SLO; DLQ behavior change; dedup policy change; labels с entity IDs;
tracing; host backend deployment.

**Implementation Rules:** Before editing, require GREEN P8.8 state, resolve the manifest as an
ordinary digest-bound P8.8 output and verify its cited P5/P6 evidence IDs. The sole
`producer-readiness/v1` edge is P8.8→P8.9; P8.10 never consumes a foreign readiness projection.
Missing/corrupt state, manifest or evidence is `dependency-not-ready`. Family names are prefixed exactly as above and type `counter`. Dedup emits
once only when the locked find-or-create result has `created=false`; DLQ emits once only on the
transactional transition into `dead`, never on terminal no-op re-dispatch. Labels are empty. Backend
failure cannot alter business outcome. A false condition forbids that family, registry row, test and
source emission; the finding records `not-added` with the P8.8 evidence. Both false is a valid D41
no-op and produces only the finding.
**Code Guidance:** Do not infer hit from equal client checksum or emit before the locked repository
result. Do not count Laravel `failed_jobs` as package DLQ. No target/result-dependent threshold is
added after observing P5/P6.
**Validation:** focused Fake/Pest tests for every enabled family; parity between true manifest flags,
registry and emissions; false flags have no code/registry occurrence; package PHPStan max and Pint;
counter amounts nonnegative; duplicate/re-dispatch fixtures prove one logical emission; finding
resolves every condition evidence ID.
**Deliverables:** zero, one or two conditionally enabled deferred metric families with tests, plus a
machine-readable enabled/not-added finding. Terminal evidence records the exact P8.8 manifest digest.
