### P4.3 — Авторитетный tier-S memory matrix run

**Intent:** Выполнить на lab-box одну валидную post-fix matrix family и сохранить raw PHP/process/
cgroup evidence для всех пяти путей, трёх размеров и трёх повторов.
**Why:** Только живой 5 GiB case способен подтвердить fixed envelope и отсутствие OOM/restart;
fixtures и unit tests доказывают механику измерения, но не memory behavior реального стека.
**Scope Included:** P8.7 live-preflight; host/dataset/image/fixture fingerprint; 45 isolated cases;
fresh container per case; sampler + Prometheus/k6 correlation; upload checksum/bytes; download
HTTP/client bytes + отдельный bounded server/object checksum; rejected-run retention;
machine-readable cell verdicts; cache/page-file declaration.
**Scope Excluded:** tier M/L; concurrency/slow-client saturation (P5/P6); package fixes; host
`drop_caches`; production/shared DB/storage; profile interpretation и debt prioritization.
**Inputs:** `plans/VLT-LOAD/phases/P4/P4.1.state.md`;
`plans/VLT-LOAD/phases/P4/P4.2.state.md`;
`plans/VLT-LOAD/decisions/D41-integrated-repair-then-audit.md`;
`plans/VLT-LOAD/findings/L-01-streaming-fix-closure.md`;
`plans/VLT-LOAD/findings/P8.7-gate-closure.md`; `plans/VLT-LOAD/phases/P8/P8.7.state.md`;
`plans/VLT-LOAD/findings/P2.8-baseline-S.md`.
**Files:** `plans/VLT-LOAD/artifacts/P4/run-manifest.json`,
`plans/VLT-LOAD/artifacts/P4/cases.json`, `plans/VLT-LOAD/artifacts/P4/samples/`,
`plans/VLT-LOAD/artifacts/P4/php-peaks.json`, `plans/VLT-LOAD/artifacts/P4/cgroup.json`,
`plans/VLT-LOAD/artifacts/P4/k6/`, `plans/VLT-LOAD/artifacts/P4/cell-verdicts.json`.
**Required Reads:** (1) `plans/VLT-LOAD/decisions/D41-integrated-repair-then-audit.md`;
(2) P4.1/P4.2 specs and GREEN terminal evidence; (3) `findings/L-01-streaming-fix-closure.md`;
(4) `findings/P8.7-gate-closure.md` and `phases/P8/P8.7.state.md` GREEN terminal evidence;

(6) `reference-env.md` tier S and `slo-gates.md` SLO-40…54; (7) `load/README.md` P4 runbook.
**Implementation Rules:** Один immutable `run_id` и один fixture family связывают все carriers.
Каждая cell имеет ровно три successful repetitions; infrastructure failure сохраняется rejected и
не заменяет successful repetition без нового attempt id. Preflight фиксирует cgroup v2, swap/cpuset,
quiet-host declaration, free disk ≥2× largest concurrent fixture, image digests, git SHA, PHP/FPM/
kernel versions и P8.7 metric reachability. OOM/restart, PID mismatch, missing terminal sample,
HTTP/client byte mismatch, server/object checksum mismatch или cgroup events delta делает cell
product-red либо evidence-invalid по
разным typed verdicts; invalid evidence не используется в P4.4. Никакого `drop_caches`.
**Code Guidance:** Сначала 5 MiB full matrix, затем 500 MiB, затем 5 GiB; это выявляет harness defect
до дорогих writes. Перед measured complete app worker/container перезапускается, parts сохраняются.
Не скрывать file-cache рост: `Pss_File` и cgroup `file` публикуются рядом с anon. Threshold failure —
наблюдение продукта, а не повод повысить ceiling или уменьшить fixture.
**Validation:** `TIER=S ./load/scripts/p4-memory.sh run --matrix`; затем `... verify --run-id <id>`
подтверждает 45 valid case attempts в 15 unique cells, exact 5 MiB/500 MiB/5 GiB bytes,
3 repetitions на cell, PID/cgroup
identity, complete samples, upload checksum parity, download HTTP/`Content-Length`/isolated
`data_received` parity, отдельный server/object checksum и разрешимые Prometheus/k6 links;
ни один download client не сохраняет/materializes response body; secret/token scan пуст;
повторный verify byte-stable. SLO verdict может быть RED и всё равно остаётся валидным raw evidence.
**Deliverables:** immutable tier-S run manifest, полные process/cgroup/PHP samples, k6 summaries и
15 aggregated cell verdicts с тремя валидными повторениями каждый и раздельными download
byte-accounting/server-object-checksum полями.
