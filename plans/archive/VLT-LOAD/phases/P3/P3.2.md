### P3.2 — Controlled workload: OP→fingerprint и top-20

**Intent:** Выполнить один авторитетный тир-S workload на восстановленном объёмном датасете и
получить доказанную связь `OP-nn → normalized query fingerprints`, top-20 impact и cluster I/O
context без смешения seed/preflight трафика.
**Why:** EXPLAIN по выбранному вручную SQL не показывает реальную частоту, параметрические классы и
N+1. Сначала нужен bounded workload corpus, из которого P3.3 выбирает actual plans.
**Scope Included:** P8.7 live-preflight; dataset/host/image/settings fingerprint; `ANALYZE` и stats
freshness; reset; warm и честно названный shared-buffer-cold-like run; основной `mixed` workload тира
S плюс обязательные точечные hotspots; `pg_stat_statements` top-20 по total execution time;
mean/stddev/calls/rows/buffers/temp/WAL; `pg_stat_io` before/after; privacy-safe Laravel trace;
47-row operation coverage matrix.
**Scope Excluded:** interpretation/индексные рекомендации; ручное изменение planner costs; tier M/L;
shared CI S0 как источник latency verdict; actual EXPLAIN; продуктовые исправления.

**Implementation Rules:** Один immutable `run_id` связывает k6, Prometheus, trace и PostgreSQL
evidence. Reset выполняется после seed/`ANALYZE`, непосредственно перед workload. Manifest фиксирует
`stats_reset`, `dealloc` before/after, table/index bytes, row/dead-row estimates, analyze timestamps,
settings/extensions и cache declaration. `dealloc_delta>0`, mismatch dataset/run id, missing P8.7
signals или неполный workload делают run invalid — evidence сохраняется как rejected, но не идёт в
P3.3. Все 47 OP получают closed verdict; `no-db`/`excluded-with-reason` требуют текст и code anchor.
`pg_stat_io` не атрибутируется запросам. Top-20 — ровно 20 fingerprint по `total_exec_time` после
исключения profiler/admin SQL; дополнительные обязательные hotspots хранятся отдельно, не подменяя
рейтинг.
**Code Guidance:** Не пытаться получить host-cold cache через `drop_caches` без отдельной authority;
restart Postgres доказывает только shared-buffer-cold-like состояние. Для parameter skew сохранить
только классы (`small|median|largest tenant`, `selective|broad`, `recent|historical`) и template hash,
не значения. Если P8.7 live-preflight красный, остановить до reset/workload и вернуть owning P8.7
continuation, а не ослаблять P3 evidence.
**Validation:** `TIER=S ./load/scripts/p3-profile.sh capture`; validator подтверждает schema и
cross-file `run_id`/`dataset_id`; top-20 содержит 20 уникальных non-admin fingerprints и
`dealloc_delta=0`; coverage содержит все 47 OP ровно один раз; secret/UUID/token scan по committed
artifacts пуст; повторный verify байт-стабилен.
**Deliverables:** валидированный run manifest, dataset/settings fingerprint, top-20 query corpus,
cluster I/O delta, privacy-safe query trace и полная OP coverage matrix.
