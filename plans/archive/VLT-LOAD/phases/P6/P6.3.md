### P6.3 — Авторитетный tier-S backlog/retry run

**Intent:** Выполнить одну immutable tier-S run family для relay, workers, retries, overlap и dirty
cardinality controls.
**Why:** Только реальный Redis worker + PostgreSQL + HTTP sink показывает queue wait, worker occupancy,
POST multiplicity и способность backlog восстанавливаться после 5×/10× burst.
**Scope Included:** D41/P8 preflight; config/image/dataset fingerprint; 20/100/200 events/s profiles;
fan-out 0/1/all; 2 workers and 50 ms sink; 2xx/500/slow/timeout; overlap and duplicate controls;
backoff/DLQ/disable state controls; 10k outbox and 5k due authoritative tier-S cases; 200/1000 endpoint
and 50k/500k due targeted probes; Redis/DB/worker/sink/Prometheus capture; machine verdicts.
**Scope Excluded:** production/shared systems; tier M/L performance claims; package fixes; network or
service kill chaos; changing accepted SLO/config after results; deleting rejected attempts.

**Implementation Rules:** One run_id binds all planes. Preflight freezes git SHA, Laravel lock
version, queue `retry_after`, worker `timeout/tries/count`, webhook timeout/backoff/max attempts,
dataset/image/sink and clock source. Product cells run three valid repetitions; overlap/state/
cardinality controls need one. At least one 30-minute 1× steady window evaluates backlog slope;
5×/10× are bounded bursts followed by measured recovery. Restore precedes each probe. OOM/restart,
deadline, ledger gap, clock drift or integrity mismatch is typed product-red vs evidence-invalid and
is never retried over silently.
**Code Guidance:** Stop/drain workers before snapshot restore. Separate business `failed|dead` from
Laravel failed_jobs. Report dispatch duplicates and HTTP duplicates independently. Slow sink below
HTTP timeout measures occupancy; over-timeout measures bounded failure. Cardinality probes may fill
Redis heavily and must use an isolated queue namespace with explicit cleanup.
**Validation:** `TIER=S ./load/scripts/p6-queue.sh run --matrix`; `verify --run-id <id>` confirms exact
cells/repetitions, 30-minute window, burst recovery, queue/DB/sink joins, transition curve, duplicate
controls, 10k/5k tier-S and all four cardinality probes; byte-stable second verify; secret scan empty;
snapshot counts/checksums restored.
**Deliverables:** immutable tier-S run family with complete relay/queue/retry/sink evidence and valid
GREEN or RED cell verdicts.
