### P6.1 — Queue lane, lifecycle ledger и evidence validator

**Intent:** Построить run-scoped lane, который раздельно фиксирует outbox claim, Redis queue lease,
worker attempt и фактический HTTP receive.
**Why:** DB status или Prometheus aggregate не доказывают отсутствие duplicate POST и не различают
relay backlog, Redis wait и package backoff; retry `created_at` также не является enqueue timestamp.
**Scope Included:** run/cell/attempt manifest; barrier; Redis pending/reserved/delayed sampler;
Laravel queued/processing/processed/exception/failed ledger; worker PID/restart ledger; DB transition
snapshots; sink-ledger schema; Prometheus/lock links; validator; positive/truncated/cross-run/
duplicate-event fixtures; dry-run/run/verify CLI.
**Scope Excluded:** product fixtures; authoritative run; package instrumentation/fixes; production
connections; Horizon; изменение P8 metric registry.

**Implementation Rules:** Closed plane enum is `product-realistic`, `overlap-control`,
`state-machine-control`, `dirty-cardinality-probe`. Every record binds run/cell/attempt, monotonic
and wall time, source, queue name and immutable config fingerprint. Queue lifecycle records UUID,
class, attempt, enqueue/start/finish/outcome without unserializing untrusted payloads. Sink ledger
stores event_id/profile/status/start/end and request ordinal, never secret/signature/body. Missing
samples are evidence-invalid. Artifacts publish atomically only after verify.
**Code Guidance:** Keep outbox rows/s, jobs/s, Redis depth, worker occupancy and HTTP receives as
separate fields. Sample Redis through framework-supported counts or exact LLEN/ZCARD keys pinned in
manifest; do not call total `size()` pending. Listener failure must not change job behavior. Redact
DSN, signing headers and payloads; cap logs.
**Validation:** `sh -n` scripts; `python3 -m unittest load/gates/test_p6_queue.py`; load Pest tests
for lifecycle ledger; validator accepts a complete fixture and rejects missing terminal marker,
cross-run event, impossible ordering, duplicate lifecycle key, negative depth and DB/sink mismatch;
`TIER=S ./load/scripts/p6-queue.sh dry-run` emits exact matrix without Docker/DB writes; compose config
and current worker route are checked.
**Deliverables:** queue orchestration lane, lifecycle/DB/Redis/sink evidence schema, negative fixtures,
validator and documented dry-run/verify workflow.
