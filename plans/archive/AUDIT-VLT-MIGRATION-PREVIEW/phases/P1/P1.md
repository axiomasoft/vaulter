# P1 — Безопасность

## Phase Context

Ось безопасности: авторизация (`AccessResolver` + ролевые драйверы), два канала шэринга,
поверхность загрузок (tus + S3 multipart), CAS-блобы с дедупликацией и GC, швы realtime-collab
(JWT + webhook), исходящие webhook через outbox, секреты и конфиг, HTTP-поверхность.

Каждый item несёт закрытый чеклист `C1..Cn`, выведенный из RAG-выжимок фазы P0 (D3):
`findings/P0-dms-security.md` (S1–S4), `findings/P0-upload-hardening.md` (U1–U7),
`findings/P0-collab-seam.md` (C1–C5). Вердикт по каждой строке чеклиста обязателен;
«выглядит корректно» — запрещённая формулировка. Находка оформляется по схеме
`artifacts/finding-template.md` и дублируется строкой в `findings/REGISTER.md`.

Фаза read-only (D2): продакшн-код не меняется. Repro — только в `artifacts/repro/<Pn.m>/`.
До заведения находки — сверка с `docs/adr/*` (D5): сознательное решение ADR даёт находку
класса «ADR устарел», а не «баг».

Фаза завершена, когда все 8 items закрыты, а `findings/REGISTER.md` содержит все находки
с severity и `file:line`. Blocker'ы не чинятся здесь — они уходят в бэклог P5.2 (D2, D7).

**Scope Included:** `packages/core/src/{Access,Sharing,Cas,Webhooks,Http,Policies,Support}`,
`packages/drive/src/{Uploads,Http}`, `packages/media/src/Cas`,
`packages/documents/src/{Collaboration,Http}`, `packages/permissions-azgard/src`,
`packages/core/config/vaulter.php`, `hocuspocus-server/src`, `e2e/docker`.
**Scope Excluded:** производительность и индексы (P4.1), DX и публичный API (P2),
расширяемость швов (P3), Filament-панель (P2.5/P4.5), Vue-фронтенд (P4.5) — кроме
случаев, где фронтенд участвует в проверяемом security-инварианте (явно указано в item'е).
