# P5 — Синтез и ремедиация

## Phase Context

> СКЕЛЕТ — не детализирован, разворачивается /task:plan-design AUDIT-VLT P5

Финальная фаза: собрать `findings/REGISTER.md` в ранжированный отчёт, превратить находки в
ремедиационный бэклог и принять решение владельца, порождать ли отдельный план починки.
Ранжирование — по `severity × эксплуатируемость × стоимость починки` (pre-mortem R4.1);
топ-10 выносится отдельным блоком. D7: закрытие AUDIT-VLT при ≥1 открытом Blocker без
решения владельца допускает только статус `🟠 Done with deviations`.

Фаза read-only по коду (D2); пишет только в `plans/AUDIT-VLT/**` и (в P5.3) в
`plans/<NEW-ID>/` при решении о ремедиации.

**Scope Included:** синтез REGISTER, ранжирование, бэклог, follow-up план, миграция
долгоживущего материала в `docs/` по Diátaxis (`plan-protocol` §12).
**Scope Excluded:** любая починка кода; закрытие плана командой `plan-close archive`
(это отдельный запуск после утверждения владельцем).
