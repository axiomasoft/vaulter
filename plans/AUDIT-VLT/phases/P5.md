# P5 — Синтез и ремедиация

## Phase Context

> СКЕЛЕТ — не детализирован, разворачивается /task:plan-design AUDIT-VLT P5

Финальная фаза: собрать `findings/REGISTER.md` в ранжированный отчёт, превратить находки в
ремедиационный бэклог и принять решение владельца, порождать ли отдельный план починки.
Ранжирование — по `severity × эксплуатируемость × стоимость починки` (pre-mortem R4.1);
топ-10 выносится отдельным блоком. D7: закрытие AUDIT-VLT при ≥1 открытом Blocker без
решения владельца допускает только статус `🟠 Done with deviations`.

Фаза read-only по коду (D2); пишет только в `plans/AUDIT-VLT/**` и (в P5.3) в
`plans/<NEW-ID>/` при решении о ремедиации.

**Scope Included:** синтез REGISTER, ранжирование, бэклог, follow-up план, миграция
долгоживущего материала в `docs/` по Diátaxis (`plan-protocol` §12).
**Scope Excluded:** любая починка кода; закрытие плана командой `plan-close archive`
(это отдельный запуск после утверждения владельцем).

### Обязательные оси (вход развёртывания, D17 — не терять)

**P5.1 — sanity-гейт «0 находок».** Ноль находок severity Major/Blocker по всей фазе P1
не является результатом сам по себе: он обязан сопровождаться строкой «обоснование:
почему» с перечнем запущенных repro и фактически прочитанных code paths. «Аудит чист»
без доказательств = дефект исполнения, а не зелёный вердикт (pre-mortem R1.3).

**P5.3 — чеклист верификации pre-mortem-митигаций.** Каждая митигация проверяется
машинно, а не декларативно:

| Риск | Митигация | Как проверить в P5.3 |
|:--|:--|:--|
| R1.1 «модель без эталона» | D3 — закрытые чеклисты | все audit-items имеют чеклист `C1..Cn`, и каждая его строка несёт вердикт |
| R1.2 «находка без доказательства» | D4 — схема находки | каждая строка REGISTER имеет `file:line` |
| R2.1 «аудит поехал в починку» | D2 — read-only | между первым и последним коммитом аудита нет коммитов, изменяющих `packages/` (`git log --oneline <first>..<last> -- packages/` пуст) |
| R2.2 «repro в пакетных тестах» | D6 — repro в artifacts/ | `find packages -path '*/tests/*' -name 'repro*'` пуст |
| R3.1 «устаревшая норма» | D16 — выжимки неизменны | `git log --oneline -- plans/AUDIT-VLT/findings/P0-*.md` не содержит коммитов после старта P1 |
| R4.3 «Blocker спрятан» | D7 — 🟠 при открытом Blocker | каждый Blocker в REGISTER имеет решение владельца либо статус плана = `🟠 Done with deviations` |

Источник осей — `findings/P0-audit-gaps.md` §1 (#9, #14).
