# P4 — W4: Качество, DX, CI + канон структуры

## Phase Context

> СКЕЛЕТ — не детализирован, разворачивается /task:plan-design VLT-REMED P4

Волна W4 бэклога (низкий прямой риск, высокий долг) плюс два items, добавленных владельцем вне реестра
находок: гармонизация внутренней доменной структуры пакетов. **B24 (supply-chain / CI-матрица /
arch-гейты) идёт ПЕРВЫМ** (D2): включённые mutation-, arch- и type-гейты страхуют остальные items волны
и — критично — массовый namespace-refactor P4.10. Структурные items идут ПОСЛЕДНИМИ, перед сквозным
ревью P5 (D10).

**Scope Included:** батчи B24 (+ F-P4.5-01 по D6), B15, B16, B17, B18, B20, B21, B19 — 45 находок:
F-P4.3-01..05, F-P4.4-01..05, F-P4.5-01, F-P4.5-02, F-P4.5-03, F-P1.8-05 · F-P1.8-03, F-P4.2-02 ·
F-P4.2-01, F-P4.1-01, F-P4.1-02, F-P4.2-05 · F-P3.2-01, F-P3.2-02, F-P3.3-01, F-P3.3-02, F-P3.5-01,
F-P3.1-03, F-P1.2-02 · F-P3.1-01, F-P3.1-02, F-P3.1-04 · F-P2.1-01, F-P2.1-04, F-P2.1-05 · F-P2.1-06,
F-P2.1-07, F-P2.5-07, F-P2.5-04 · F-P2.1-02, F-P2.1-03, F-P2.4-01, F-P2.5-01, F-P2.5-02, F-P2.5-03,
F-P2.5-05, F-P1.8-04, F-P2.5-08. Плюс P4.9/P4.10 — канон структуры (вне реестра находок, D10).

**Scope Excluded:** любые поведенческие фиксы, не входящие в перечисленные батчи. P4.10 —
**только перенос без изменения поведения**: правка логики внутри переносимого класса запрещена.

**Обязательные оси развёртывания** (вход `/task:plan-design VLT-REMED P4`):

1. **B24 → P4.1 (первым; sonnet/medium + RAG).** CVE `firebase/php-jwt` (CVE-2025-45769) и `happy-dom`
   (critical RCE в devDependency); устаревшие мажоры (`@tiptap` 2.x → 3.x — F-P4.5-01 по D6;
   hocuspocus 2.x → v3/v4); честная CI-матрица Laravel/Filament; arch-запреты `App\*` и граница
   публичного API; включение mutation- и Rector-гейтов; `composer test:types` в CI; healthcheck e2e;
   пиннинг образа `latest`; объявленная политика версий. Ось: статусы CVE и актуальные мажоры
   **верифицируются RAG на момент исполнения** (`general:verify-claims`), не берутся из памяти.
   Мажор `@tiptap` при разрастании — эскалация и вынос в отдельный план (pre-mortem, остаточный риск).
2. **B15 → P4.2.** Экранирование LIKE-wildcard в поиске по имени узла; детект циклов на чтении.
3. **B16 → P4.3.** Индекс `trashed_at`; снятие избыточных индексов с общим префиксом; `withMaxDepth`
   на обходе предков (путь авторизации!); стабильный уникальный ключ курсорной пагинации в трёх фидах.
4. **B17 → P4.4.** Молчащие швы: install-hint при громком падении кросс-пакетных швов; докблоки
   приведены к коду; «validated on boot» vs фактический ленивый резолв `PanelRegistry`; мёртвые хуки
   панели `fillNode`/`presentNode`/`pipes`. Ось: докблок правится под код ЛИБО код под докблок —
   решение по каждому шву фиксируется, «переписать комментарий» по умолчанию не годится.
5. **B18 → P4.5.** `DriveNameRules` как шов расширения + lang-ключ сообщения; `filenameFor` как точка
   расширения.
6. **B20 → P4.6.** Гигиена публичного API: докблок фасада на все 12 методов; namespace в доке;
   статический реестр-кеш убран за фасад.
7. **B21 → P4.7.** Release-readiness: per-package CHANGELOG для split-артефактов Packagist; политика
   депрекации; `peerDependencies` и версия `@vaulter/vue`. Ось: сюда же стекается **`UPGRADING.md`**
   со всеми ломающими изменениями плана (D3).
8. **B19 → P4.8 (sonnet/low).** Docs-drift: удалённый API в reference-доках; пропущенные маршруты,
   команды и config-ключи; битые якоря `errors.md`; мёртвый ключ `permission_resolver` (по нему реальный
   хост написал нерабочую интеграцию); CORS-гайд; PHPStan-level в CONTRIBUTING.
9. **P4.9 — Канон структуры (ADR + arch-тесты, БЕЗ переноса; opus/high).** Зафиксировать вариант A
   (D10): layer-first + доменный под-namespace, схема `vaulter-core` (`Actions/Sharing`, `Models/Drive`,
   `Enums/Webhooks`). Инвентаризация ВСЕХ шести PHP-пакетов; ADR `docs/adr/`; arch-тесты (Pest Arch),
   фиксирующие канон и падающие на текущей раскладке `documents`/`drive`. Основание — скиллы
   `php:laravel-structure` (layer-mirror rule) и `quality:test-strategy` (Arch-тесты).
10. **P4.10 — Приведение пакетов к канону (перенос; opus/high).** `packages/documents`: плоские
    `Enums/`, `Events/`, `Actions/` получают доменный под-namespace; домен-папка `Documents/`
    раскладывается по слоям. `packages/drive/src/Uploads/*` распускается: `Uploads/Actions` →
    `Actions/Uploads`, `Uploads/Models` → `Models/Uploads` и т.д. `media`, `filament`,
    `permissions-azgard` — проверить и выровнять. Ось: дисциплина `php:namespace-refactor-safety`
    (three-phase alias → правка `use` → hard rename; якорь find-replace на FQN, не на голом токене).
    Обязательны: обновление morph-алиасов, FQCN-дефолтов в `config/vaulter.php`, ссылок в `docs/`,
    строка в `UPGRADING.md`. Поведение не меняется — доказательство: сьют зелёный БЕЗ правки тестов
    сверх `use`-строк.
