# P1 — W1: Быстрые высоко-эксплуатируемые

## Phase Context

> СКЕЛЕТ — не детализирован, разворачивается /task:plan-design VLT-REMED P1

Волна W1 бэклога (`plans/AUDIT-VLT/findings/P5.2-remediation-backlog.md` §5): «быстрые победы» —
высокая эксплуатируемость при дешёвой починке (E3/F1 по шкалам P5.1 §3.1). Максимум снятого риска на
минимум усилия, сразу после Blocker'ов. Items автономны, порядок внутри фазы произволен.

**Scope Included:** батчи B2, B8, B14, B13 — 13 находок: F-P1.3-04, F-P1.11-03 · F-P1.3-01, F-P1.3-02,
F-P1.3-03, F-P1.3-05 · F-P1.8-01, F-P1.4-09, F-P4.2-03, F-P4.2-04 · F-P1.8-02, F-P1.5-04, F-P1.7-04.

**Scope Excluded:** ремедиация корзины (F-P1.12-* → P2.2); tenant-скоуп листингов (→ P2.3); индексы и
курсорная стабильность (F-P4.2-01/02/05 → P4.2, P4.3).

**Обязательные оси развёртывания** (вход `/task:plan-design VLT-REMED P1`, не пожелание):

1. **B2 → P1.1.** `X-Content-Type-Options: nosniff` + whitelist `Content-Type` на всех путях
   download/share. Ось: заголовок ставится в ОДНОМ шве, а не в двух контроллерах врозь.
2. **B8 → P1.2.** Убрать presign-обход PHP (нарушение D15 плана AUDIT-VLT: скачивание всегда через
   `DownloadController`); перепроверять права issuer'а при потреблении share-ссылки (confused deputy);
   дефолтный TTL публичной ссылки; скрыть сырой id узла в `SharedNodeResource`. Ось: D15 — сознательное
   решение владельца, presign-путь удаляется, а не конфигурируется.
3. **B14 → P1.3.** Throttle публичных маршрутов и upload-сессий; устранить N+1 листинга через
   `AccessResolver::abilitiesFor`; keyset вместо offset на `shared`. Ось: rate-limit пакета обязан быть
   config-first и не навязывать хосту именование лимитеров.
4. **B13 → P1.4.** Снять `$guarded = []` во ВСЕХ 16 моделях пакета одним PR. Ось: закрывается только при
   зелёном ПОЛНОМ сьюте всех 6 PHP-пакетов (pre-mortem R9: Actions могли полагаться на unguarded `fill()`).
   Ломающее изменение — строка в `UPGRADING.md` (D3).
