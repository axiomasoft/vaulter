## Method

- Plugin: `pestphp/pest-plugin-mutate` **v4.0.1** (`d9b32b60b238`) in all five package lockfiles; PHP `/usr/bin/php8.4` 8.4.25, `PCOV_ENABLED=1`, `xdebug.mode=off`.
- Honest path: sequential, `--clear-cache`, **no `--parallel`**, **no `--min`** so the full denominator finishes. Score = `(tested + timeout) / total * 100`.
- Skip matrix (archived D4, not re-authored): drive/documents PG; core/media union PG+SQLite (killed if killed in either, merge by mutation ID); filament SQLite.
- Runner: [run-one.sh](R02-checks/run-one.sh) via `script -qefc` for a TTY (redirected Pest otherwise emits PAO JSON). Core cwd is the repo root with `--path=packages/core/src`; other packages cwd `packages/<pkg>` with `--path=src`.
- Wall clocks come from `/usr/bin/time` (`time.txt`). `summary.json` `duration_seconds_reported` is a parser last-`Duration:` artefact (drive reported 110.08 s vs 4h11m wall).

`--parallel` on v4.0.1 remains a false 100%: the child inherits argv, ParaTest dies, non-zero exit is counted as killed ([P0.1](../archive/VLT-MUT/findings/P0.1-parallel-defect.md)).
