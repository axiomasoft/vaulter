# D08 — Завершение повторной проверки дизайна P0 в текущей сессии (accepted)

**Actor:** repository owner; фиксирует gpt-6-sol/high.
**Evidence:** явное сообщение владельца после исправлений D07:
«Ну да, это правило общее, но в данном случае оно бессмысленно, поэтому давай закрывай до грин,
всё что нужно там осталось и можем уже приступить к работе.»;
findings/design-audit.md; findings/design-remediation.md.

## Решение

1. Для завершения исправлений дизайна P0 разрешена ограниченная перепроверка DA01–DA06
   текущим sol/high в этой сессии. Ещё один полный независимый design audit не требуется.
   Это уточнение D03 п.3 и D07 п.7 только для данной повторной проверки после исходного
   независимого RED; правила последующих фаз этим решением не меняются.
2. Если исправленные замечания закрыты доказательствами и актуальные проверки проходят,
   записать GREEN текущего finish fingerprint. В отчёте и журнале явно указать
   same-author recheck по D08; не выдавать его за независимый аудит.
3. Исходный RED и отчёт остаются в истории. Требования OPUS, предметные Validation,
   full-review B0-A, фазовый аудит по отдельному audit-admission/v2 и owner gates
   O-1/O-2/O-3-CI/O-3-PR сохраняются. GREEN дизайна не означает выполнение items.
4. Завершение дизайна передаёт следующий запуск P0.1 по execution-sheet. Реализация
   и её приёмка имеют отдельные предметные проверки; данное решение их не заменяет.

## Почему

Исходный план уже проверен независимо; найденные дефекты исправлены по D07.
Повторная проверка нужна для этих изменений, а не для повторения всего аудита.
Владелец явно просит закончить на GREEN в текущей сессии, исключив затраты
на ещё один полный независимый проход дизайна.

## Последствия

При успешной перепроверке снимается только gate дизайна текущей P0. В evidence явно
сохраняется ограничение: автор сам проверял исправления. Исполнение и приёмка P0
проводятся по прежним контрактам и не объявляются завершёнными.
