## Item spec
### P1.7 — Типы колонок ключей хоста

**Intent:** Колонки, хранящие ключи хоста (владелец storage, субъект grant, tenant, автор и все actor-колонки),
типизируются отдельным ключом `vaulter.ids.host_keys` (по умолчанию `string` = `varchar(64)`), а не стратегией ID Vaulter,
так что хост с UUID/bigint/ULID-ключами пишет и читает grants, activity и provisioning при любой `ids` стратегии (N02, AD25, V23).

**Why:** OPUS 13 P1.7, 02 D25, 08 §2–§3 (миграция №3); V23. Сегодня `PanelTablesBuilder` создаёт эти колонки через
`$ids->reference()`/`$ids->actor()` (`packages/core/src/Schema/PanelTablesBuilder.php:162–755`, `AutoIncrementIds.php:22–30`,
`UlidIds.php:31–39`): при `ids.default = ulid` колонки `char(26)` и UUID хоста (36 символов) не вставляется на PostgreSQL; при
`bigint` — ULID/UUID-пользователь не может получить grant или попасть в аудит.

**Scope Included:**
1. Конфиг: `packages/core/config/vaulter.php` блок `ids` — ключ `'host_keys' => env('VAULTER_HOST_KEYS', 'string')`
   (`string|bigint|uuid|ulid`) с комментарием; `packages/core/src/Support/Config.php` — `hostKeyType(): string`
   (значение вне четырёх — `InvalidArgumentException('[Vaulter] Unknown vaulter.ids.host_keys [<v>]; expected string|bigint|uuid|ulid.')`).
2. `packages/core/src/Schema/HostKeyColumns.php` (new, `final class`): `add(Blueprint $table, string $column, bool $nullable, bool $index): void`
   по `Config::hostKeyType()`: `string` → `$table->string($column, 64)`; `bigint` → `unsignedBigInteger`; `uuid` → `uuid`;
   `ulid` → `char($column, 26)`; затем `nullable($nullable)` и `->index()` при `$index`. `sqlType(string $driver): string` —
   целевой SQL-тип для миграции: PG `varchar(64)|bigint|uuid|char(26)`, MySQL/MariaDB `varchar(64)|bigint unsigned|char(36)|char(26)`.
3. `PanelTablesBuilder`: ровно 27 колонок переходят на `HostKeyColumns::add()` с прежними `nullable` и наличием индекса
   (индекс был у `reference()`, у `actor()` не было):
   `tenant_id` (index, nullable) в `storages`, `nodes`, `blobs`, `files`, `file_versions`, `node_grants`, `node_shares`,
   `node_comments`, `document_versions`, `upload_sessions`, `activity` (через приватный `tenant()`, строка 1173);
   `storages.owner_id` (index, not null, строка 164); `node_grants.subject_id` (index, not null, 419);

   `nodes.trashed_by` (223), `nodes.created_by` (226), `nodes.updated_by` (227), `files.created_by` (334),
   `file_versions.created_by` (365), `node_grants.granted_by` (434), `node_shares.granted_by` (491),

   `IdStrategy::actor()` в контракте остаётся (удаление — P2.1).

    private function convert(bool $restore): void
    {
        $connection = app(VaulterDatabase::class)->connection();
        $driver = $connection->getDriverName();

        if ($driver === 'sqlite') {
            return;
        }

        $schema = $connection->getSchemaBuilder();
        $grammar = $connection->getQueryGrammar();

        foreach (self::COLUMNS as $entity => $columns) {
            $table = Config::table($entity);

            if (!$schema->hasTable($table)) {
                continue;
            }

            $actual = array_column($schema->getColumns($table), null, 'name');

            foreach ($columns as $column => $nullable) {
                if (!isset($actual[$column])) {
                    continue;
                }

                $type = $restore
                    ? $this->originalType(new Blueprint($connection, $table), $entity, $column, $driver)
                    : HostKeyColumns::sqlType($driver);

                // type_name alone cannot distinguish varchar(26) from varchar(64)
                // or a signed bigint from an unsigned MySQL bigint.
                $actualType = str_replace(['character varying', 'character'], ['varchar', 'char'], strtolower($actual[$column]['type']));
                if ($actualType === $type) {
                    continue;
                }

                $wrappedTable = $grammar->wrapTable($table);
                $wrappedColumn = $grammar->wrap($column);

                if ($driver === 'pgsql') {
                    $cast = match ($type) {
                        'bigint' => 'bigint',
                        'uuid' => 'uuid',
                        default => 'text',
                    };
                    $connection->statement("ALTER TABLE {$wrappedTable} ALTER COLUMN {$wrappedColumn} TYPE {$type} USING {$wrappedColumn}::{$cast}");
                } else {
                    $null = $nullable ? 'NULL' : 'NOT NULL';
                    $connection->statement("ALTER TABLE {$wrappedTable} MODIFY {$wrappedColumn} {$type} {$null}");
                }
            }
        }

    {
        $strategy = app(IdStrategyResolver::class)->resolve();

## New file packages/core/src/Schema/HostKeyColumns.php
<?php

declare(strict_types=1);

namespace Vaulter\Schema;

use Illuminate\Database\Schema\Blueprint;
use InvalidArgumentException;
use Vaulter\Support\Config;

final class HostKeyColumns
{
    public static function add(Blueprint $table, string $column, bool $nullable, bool $index): void
    {
        $definition = match (Config::hostKeyType()) {
            'string' => $table->string($column, 64),
            'bigint' => $table->unsignedBigInteger($column),
            'uuid' => $table->uuid($column),
            'ulid' => $table->char($column, 26),
        };

        $definition->nullable($nullable);

        if ($index) {
            $definition->index();
        }
    }

    public static function sqlType(string $driver): string
    {
        if (!in_array($driver, ['pgsql', 'mysql', 'mariadb'], true)) {
            throw new InvalidArgumentException('[Vaulter] Unsupported host-key SQL driver ['.$driver.'].');
        }

        return match (Config::hostKeyType()) {
            'string' => 'varchar(64)',
            'bigint' => $driver === 'pgsql' ? 'bigint' : 'bigint unsigned',
            'uuid' => $driver === 'pgsql' ? 'uuid' : 'char(36)',
            'ulid' => 'char(26)',
        };
    }
}
