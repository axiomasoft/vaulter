PurgeTrashCommand материализует eligible roots, обрабатывает каждый в отдельной Vaulter transaction с tree→root re-lock и свежим subtree; physical purgeSubtree в той же transaction удаляет node rows и FK-cascade DocumentRevision/content/yjs_state. При ошибке корня откатывает только этот root, skip+report (root key, correlationId, safe exception code, без content/token), продолжает остальные; exit 0 без ошибок, exit 1 при любой root failure после завершения всех. Потерявший eligibility restored root — безопасный skip, не ошибка. trash()->purge(node): void атомарно удаляет один root/subtree; failure rollback+report и исходное исключение, не silent success. trash()->empty(): int обходит все authorized roots отдельными transactions; unauthorized roots skip, ошибки rollback+report не прерывают остальные, после полного обхода повторно бросает первое исходное unexpected исключение; HTTP получает его штатный Problem status или 500, успешные корни уже committed. При отсутствии unexpected failures empty возвращает число успешно purged корней (не узлов); ошибки и unauthorized skips в число не входят. PHP signatures 05 не меняются.
