## 01-review.md — 4. Новые находки (не было ни в аудите, ни у Codex) / N09 (S2). Один список middleware на три разные поверхности

- `01:85398e12`

Все маршруты — защищённые, публичные share-ссылки (`share/{token}`) и server-to-server колбэки хаба
(`collab/authenticate|store`) — оборачиваются одним `Config::middleware()` (`packages/core/routes/api.php:22-23`).
Добавить `auth:sanctum` нельзя, не сломав публичные ссылки и хаб. По умолчанию `['api', metrics]`: при чистой
установке каждый защищённый маршрут отвечает 403 (fail-closed, но не документировано ни в install, ни в quick-start).


## 01-review.md — 4. Новые находки (не было ни в аудите, ни у Codex) / N10 (S2). Глобальные `Route::bind('node')` и `Route::bind('storage')`

- `01:d7ffc06b`

`VaulterServiceProvider::registerRouteBindings` (строки 397, 403) регистрирует биндинги **для всего приложения**:
любой маршрут хоста с параметром `{node}` или `{storage}` начинает резолвиться в модели Vaulter. Биндинг `node`
ищет по глобальному ID без учёта drive/tenant.

## 10-http-api-v1.md — 3. Резолв ресурсов вместо глобальных биндингов

- `10:a0cf2efb`

Глобальные `Route::bind('node'|'storage')` удаляются (N10). Параметры маршрутов — `{drive}`, `{node}`,
`{revision}`, `{grant}`, `{share}`, `{comment}`, `{upload}` — скаляры. `HttpResourceResolver`
(core `Http\Support`) выдаёт модели с фильтром по tenant (D10), а для вложенных — по родителю
(`revision` принадлежит агрегату `node`, `grant`/`share`/`comment` — узлу). Не найдено → 404 `node_not_found`
(или `*_not_found` соответствующего ресурса). Контроллер получает handle:
`$drive = Vaulter::drive($resolvedDrive)` (actor — пользователь запроса через guard стека).
