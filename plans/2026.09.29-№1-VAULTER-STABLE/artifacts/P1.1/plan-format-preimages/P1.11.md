### P1.11 — Метаданные и URL

**Intent:** Все ссылки на репозиторий в метаданных пакетов, сообщениях ошибок и install-команде ведут на
фактический репозиторий `github.com/axiomasoft/vaulter`; vendor `axioma-studio/*` (имена пакетов) не меняется.

**Why:** OPUS 13 P1.11 (сужен D02 п.2: README переписывается в P7.6), 01 §2 («Ссылки homepage/support/docs — да;
vendor `axioma-studio/*` не менять … `VaulterException::docs()` и `askToStarRepoOnGitHub` ведут на неверный owner»).
`git remote -v` → `https://github.com/axiomasoft/vaulter.git`; `packages/vue/package.json` уже указывает `axiomasoft`.

**Scope Included:**
1. Заменить `https://github.com/axioma-studio/vaulter` → `https://github.com/axiomasoft/vaulter` (с сохранением
   суффиксов `/issues`, `/blob/main/...`) ровно в 9 файлах:
   `composer.json` (корень, `homepage`), `packages/{core,drive,documents,media,filament,azgard}/composer.json`
   (`homepage`, `support.issues`, `support.source`), `packages/core/src/Exceptions/VaulterException.php:16` (`docs()`),
   `packages/documents/src/Collaboration/NodeCollaborationDriverManager.php:49`.
2. `packages/core/src/VaulterServiceProvider.php:76`: `->askToStarRepoOnGitHub('axiomasoft/vaulter')`.
3. Тест, сверяющий URL: `packages/drive/tests/Feature/R07ExceptionContractsTest.php:25` → новый owner (других тестов с этим URL нет — Code Guidance).
4. `CHANGELOG.md [Unreleased]` (Fixed: repository URLs — N20/E6, D02 п.2).

**Scope Excluded:** README и docs-сайт (P7.6, D02 п.2); vendor-имена `axioma-studio/vaulter-*`, текстовые упоминания
пакетов в сообщениях (`owned by axioma-studio/vaulter-documents` — это имена пакетов, не URL); `docs/reference/errors.md`
и ссылки RFC 9457 `type` (P6.2).

**Inputs:** `plans/2026.09.29-№1-VAULTER-STABLE/artifacts/P1-design/P1.11-opus.md` ·
`plans/2026.09.29-№1-VAULTER-STABLE/decisions/D02-owner-questions.md` · `packages/core/src/Exceptions/VaulterException.php`

1) `plans/2026.09.29-№1-VAULTER-STABLE/decisions/D02-owner-questions.md` п.2.

**Authority:** routine

**Implementation Rules:**
- Меняются только URL `github.com/axioma-studio/vaulter…`; строки вида `axioma-studio/vaulter-<pkg>` (имя пакета) не трогаются.
- Репозиторий приватный (`gh repo view axiomasoft/vaulter --json visibility` → `PRIVATE`), поэтому анонимный HTTP 404 —
  не дефект; существование цели проверяется аутентифицированным `gh api`.

**Code Guidance:** инвентарь до правки: `grep -rln "github.com/axioma-studio/vaulter" --include=*.php --include=*.json . | grep -v -e vendor -e node_modules -e '^./plans/' -e '^./audits/'`
→ ровно 10 путей (9 файлов п.1 + `packages/drive/tests/Feature/R07ExceptionContractsTest.php`); после правки → пусто.

**Validation:**
- Code Guidance после правки → пустой вывод.
- `grep -n "askToStarRepoOnGitHub('axiomasoft/vaulter')" packages/core/src/VaulterServiceProvider.php` → 1 строка.
- `gh api repos/axiomasoft/vaulter/contents/docs/guide/errors.md --jq .path` → `docs/guide/errors.md` (цель `docs()` существует).
- `for f in composer.json packages/*/composer.json; do scripts/php84 composer validate --no-check-publish "$f" || exit 1; done` → exit 0.
- Гейт core и гейты drive, documents → exit 0.

**Deliverables:** корректные URL в metadata, `docs()`, install-команде и тестах.
