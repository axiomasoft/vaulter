### P0.1 — Окружение и базовая линия

**Intent:** Сделать окружение исполнения воспроизводимым (обёртка PHP 8.4, preflight тестовых БД) и зафиксировать
фактический статус всех текущих lanes CI на `main` в `findings/baseline.md`: каждый lane либо зелёный по exit 0, либо
его падение классифицировано и отнесено к владельцу.

**Why:** OPUS 13 P0.1 («все существующие suites зелёные или каждое падение описано как отдельный пункт»); D04 (хост PHP
8.3, пакеты требуют `^8.4`; роли БД нет); OPUS README «Границы» — тесты при аудите не запускались. Без базовой линии
красное после P1 нельзя отличить от унаследованного.

**Scope Included:**
1. `scripts/php84` — по образцу копии `artifacts/P0-design/corex-php84.reference.sh`: shim-каталог `build/php84/bin/php` → `php8.4` (или `$PHP84_BIN`)
   первым в `PATH`, затем `exec "$@"`; `--check` проверяет `PHP_VERSION` 8.4.* и расширения `ctype curl dom fileinfo gd
   intl bcmath mbstring openssl pcntl posix pcov pdo_pgsql pdo_mysql pdo_sqlite sqlite3 sodium tokenizer xml zip`, печатает
   `php84 OK: <version>` или `php84: missing extensions: …` (exit 1).
2. `scripts/db-preflight.sh <pgsql|mysql>` — читает `DB_HOST/DB_PORT/DB_DATABASE/DB_USERNAME/DB_PASSWORD` с дефолтами D04;
   отказ (exit 1), если имя БД не оканчивается на `_test`; проверка подключения (`psql -Atc 'select version()'` /
   `mysql -e 'select version()'`); при ошибке аутентификации — exit 2 и печать точной команды owner gate из D04 (O-1/O-2);
   успех — `db-preflight OK: <driver> <database> (<server version>)`, exit 0.
3. Прогон lanes (таблица ниже) и запись `plans/2026.09.29-№1-VAULTER-STABLE/findings/baseline.md`.
4. CI-гигиена: в `.github/workflows/filament.yml` шаг Rector с `|| true` — удалить `|| true`, **если**
   `(cd packages/filament && "$(git rev-parse --show-toplevel)/scripts/php84" vendor/bin/rector process --dry-run --no-progress-bar)` даёт exit 0; иначе
   не трогать и записать находку `B-nn` (владелец — P2.2).
5. `CONTRIBUTING.md` — раздел «Локальное окружение»: `scripts/php84 --check`, `scripts/db-preflight.sh`, команда PG-lane.

**Authority:** routine

**Implementation Rules:**
- Первый шаг — `scripts/php84 --check` и `scripts/db-preflight.sh pgsql`; exit 2 preflight → стоп item со статусом
  `🔴 Blocked` и командой O-1 в Escalation, не подмена PG-лейнов SQLite.
- Команда lane не изменяется; если job требует секрет/внешний ресурс — строка `env-blocked` с точной причиной.
- Классификация каждой не-зелёной строки: `red-owned:<OPUS item>` (падение, которое устраняет пункт OPUS, со ссылкой на
  N/E/V), `red-new:B-nn` (новая находка с предложенной фазой-владельцем), `env-blocked`, `not-applicable`. Других
  классов нет; «пропущено из-за времени» не допускается.
- Проверить и записать: запускаются ли на PG-лейне CI тесты с `pcntl_fork` (расширения `pcntl`/`posix` в `setup-php`)
  или они `skipped` — отдельная строка `B-nn`, владелец P0.2.
- Скрипты — bash `set -euo pipefail`, без новых зависимостей.

**Code Guidance:** формат `findings/baseline.md` — заголовок первого уровня «Baseline — main @ `<sha>` (дата)»;
строка окружения (PHP/PostgreSQL/MySQL/Node версии); таблица lanes с колонками
`Lane | Источник | Команда | Exit | Passed/Failed/Skipped | Время | Класс`, например
`root L13 sqlite | tests.yml:test | vendor/bin/pest --ci --coverage --min=80 … | 0 | 1234/0/56 | 3m10s | green`;
раздел второго уровня «Находки» с таблицей `ID | Lane | Симптом (первые строки вывода) | Владелец | Основание`.

Полные логи — `plans/2026.09.29-№1-VAULTER-STABLE/artifacts/P0.1/<lane>.log` (коммитятся, ≤ 1 МБ каждый; длиннее —
хвост 2000 строк).

**Validation:**
- `scripts/php84 --check` → `php84 OK: 8.4.*`, exit 0; негатив: `PHP84_BIN="$(command -v php8.3)" scripts/php84 --check` → exit 1.
- `scripts/db-preflight.sh pgsql` → `db-preflight OK: pgsql vaulter_test (PostgreSQL 16.*)`, exit 0; негатив:
  `DB_DATABASE=vaulter scripts/db-preflight.sh pgsql` → exit 1 (не `_test`).
- `findings/baseline.md`: по строке на каждый job из таблицы Scope; ни одной строки без `Exit` и `Класс`; каждая
  `red-*` ссылается на лог в `artifacts/P0.1/`.
- `git status --porcelain composer.json packages/*/composer.json` пусто (L12-лейн не протёк в дерево).
- `bash -n scripts/php84 scripts/db-preflight.sh` exit 0; `python3 <task>/scripts/plan-lint.py "plans/2026.09.29-№1-VAULTER-STABLE"` без ошибок.

**Deliverables:** обёртка PHP 8.4 и preflight БД; `findings/baseline.md` с логами; раздел окружения в CONTRIBUTING;
условная правка `filament.yml`.
