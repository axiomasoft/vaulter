# P1.7 — Кандидаты на сокращение тестов и стоимость (без удаления)

База: HEAD `bc8e21b4`. Метод: только чтение кода и готовых артефактов; **ни один тест не запускался, не удалялся и не сводился**
(указание владельца: «длинные прогоны не запускай, только тесты по коду»; D4/run-policy п.1).

## Границы и честность замеров (П14)

- Измерено в P1.1 только 4 файла (media-find, drive-api, media-atomic ×3 движка, core-openapi/http). Полного таймингa по файлам **нет**
  (`full_timing_status=deferred_to_P1.9`). Колонка «выигрыш, с» ниже заполнена только там, где есть измерение; иначе — «не измерено».
- Единственный измеренный крупный фактор: MySQL-провижининг ~85–98 с на запуск даже для 1 файла, PG 5–14 с, SQLite 1–8 с
  (baseline.md, нагрузка машины 5–10, 2 повтора). Он не зависит от числа тестов в файле — сокращение тестов его не уменьшает.
- Два класса вердикта (rules пункта):
  - **ЭП** — «доказано эквивалентным повтором»: значение измерения не меняет ветку кода (проверено по коду, не по названию).
  - **М/Р** — «требует mutation/ревью»: к удалению **не предлагается** до D3-разрешения; только описание и дешёвый вариант.
- Удаления D21 (легаси 0.x) в этом отчёте **не** повторяются и от новых предложений отделены: они делаются в P1.10 (done) по своему инвентарю.
