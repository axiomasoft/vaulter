### P8.4 — Seam'ы §5.2 — стриминг и память (10 metric families, сердце P8-минимума)

**Intent:** Реализовать метрики `slo-gates.md` §5.2 — детекторы стриминга-vs-RAM:
**`vaulter_request_peak_memory_bytes`** (gauge, `memory_get_peak_usage(true)` в terminate-middleware —
отличает «стримит» от «держит файл в RAM», без неё L-01 непроверяем), `vaulter_upload_bytes_total`,
`vaulter_upload_chunk_duration_seconds`, `vaulter_upload_conflict_total`, `vaulter_assemble_bytes_total`/
`vaulter_assemble_duration_seconds` (в `complete()` — до/после фикса L-01), `vaulter_download_bytes_total`,
**`vaulter_download_stream_active`** (gauge — очередь за FPM-воркером), `vaulter_download_ttfb_seconds`,
`vaulter_throttled_total`.
**Why:** Питает SLO-40…54 — сердце нагрузочной оси (память/throughput стримов). `request_peak_memory_bytes`
и `assemble_*` — приборы, которыми P4 померит РЕЗУЛЬТАТ фикса L-01; их надо поставить **до** фикса.
**Scope Included:** инструментация точек §5.2 из спеки; peak-memory terminate-middleware в `load/` (лейблы
`operation`/`tier`); `assemble_*` вокруг сборки в `S3MultipartHandler::complete()`; host collector
`download_stream_active` как абсолютный snapshot; server first-write `download_ttfb_seconds` и PHP
attempted `download_bytes_total`; Fake-ассерт на каждую package-метрику.
**Scope Excluded:** **фикс L-01** (`complete()` в RAM) — dev-срез, ждёт D11 (VLT-MUT drive ≥95); §5.1/§5.3;
health.

**Implementation Rules:** `request_peak_memory_bytes` — в terminate-фазе middleware (после отдачи ответа),
`true` в `memory_get_peak_usage`. `assemble_bytes_total`/`assemble_duration_seconds` вешаются вокруг
конкатенации в `complete()` — **не переписывая её** (лейбл `size_bucket`). `download_stream_active`
получает абсолютное значение от host collector (`DownloadStreamMetrics` читает php-fpm status `full`, потолок = `pm.max_children`);
package `DownloadController` **не** вызывает gauge и не делает `+1/-1`. `route` для throttle — logical ids `observability-spec.md` §9. `download_ttfb_seconds` — server
first-write; `download_bytes_total` — bytes read/attempted PHP. `upload_bytes_total` лейбл
`protocol` (`tus`/`s3`/`single`). Все package-вызовы — через инжектированный `MetricsRecorder`.
**Code Guidance:** **D31 — критично для этого item'а:** `S3MultipartHandler.php` несёт 38 выживших
мутантов VLT-MUT; seam допустим ТОЛЬКО потому, что аддитивен — ни один `===`/элемент массива/ветка не
трогается, добавляется лишь замер вокруг существующей сборки. Если для замера потребуется изменить
логику сборки — **СТОП, это уже фикс L-01**, эскалация (это dev-срез за D11, не P8). **Анти-самообман:**
