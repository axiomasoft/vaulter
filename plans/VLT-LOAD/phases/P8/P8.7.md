### P8.7 — Гейт-верификация P8-минимума + замер overhead инструментации

**Intent:** Доказать, что P8-минимум реально снимает блокировку P3–P7: прогнать харнесс P2 с
подключённым recorder'ом (Fake или OTel-мост) и показать, что **66/96 строк гейта перестали быть
`not-checkable`** (метрики эмитятся с верными именами/типами/лейблами §5). Параллельно — отдельный
with/without-прогон, измеряющий overhead инструментации (митигация Risk фазы), и вердикт «overhead в
бюджете».
**Why:** Это item, который **флипает гейт** P8-минимума в «выполнен» → P3–P7 стартуют. Без независимой
проверки «seam'ы есть, но гейт всё равно не сходится» осталось бы незамеченным (ровно риск, который D9
закрывал). Overhead-замер — потому что OTel/FPM-инструментация сама искажает нагрузочный замер (§Risk).
**Scope Included:** прогон харнесса P2 (профиль S0/`smoke-perf` минимум) с recorder'ом; сверка каждой из
50 metric families §5 «эмитится ↔ ожидается»; пересчёт «not-checkable → checkable» по строкам гейта; with/without
overhead-прогон (2× harness, δ латентности/RSS от инструментации); отчёт `findings/P8.7-gate-closure.md`.
**Scope Excluded:** сам гейт P3–P7 (это уже те фазы); подключение прод-backend'а (host); полный тир-S
absolute baseline (провенанс P2.8 — отдельный долг).
**Inputs:** реализованные seam'ы P8.3–P8.6 · харнесс `load/` (P2) · `slo-gates.md` §5 (50 families — чеклист)
· `slo-gates.md` §3 (66 not-checkable строк — что должно закрыться) · `findings/P2.8-baseline-S.md` (fingerprint
lab-box) · `load/baselines/*`.
**Files:** `plans/VLT-LOAD/findings/P8.7-gate-closure.md` (новый); `load/app/Observability/LoadExpositionRecorder.php`; `load/app/Observability/RedisMetricsRegistry.php`; `load/app/Observability/lua/histogram_observe.lua`; `load/app/Http/Controllers/MetricsController.php`; `load/routes/metrics.php`; `load/app/LoadServiceProvider.php` (bind adapter + mount `/metrics`); `load/docker/prometheus.yml` (job `vaulter-sut`); `load/docker-compose.load.yml`; `load/gates/perf-assert.py`; `load/gates/_slo_table.py`; `load/gates/promql_map.py`; `load/gates/fixtures/`; `load/scripts/p8-metric-matrix.sh`; `load/scripts/run.sh`.
**Required Reads:** (1) `slo-gates.md` §5 (50 families) + §3 (строки гейта); (2) `phases/P2/P2.md` P2.7/P2.8
Completion Notes (как гонять harness, что было not-checkable); (3) `findings/P2.8-baseline-S.md`; (4)
`load/scripts/run.sh` + `load/gates/*`; (5) реализованные seam'ы P8.3–P8.6.
**Implementation Rules:** Прогон — обвязкой P2 плюс матрица `observability-spec.md` §10. Recorder в SUT —
host `LoadExpositionRecorder` + Redis registry + `/metrics` scrape (не Fake как единственный proof).
Сверка 50↔50 — машинная по scraped names (zero-ok для условных counters, если family зарегистрирована).
PromQL — только шаблоны `observability-spec.md` §8 через `promql_map.py`; reader **не** запрашивает голое имя histogram. Redis — run-scoped + Lua (`+Inf == _count`). Fixtures: histogram, counter, run-max gauge, compound. Overhead: два прогона одного датасета
(recorder on / Null off), δ p95/RSS фиксируется; если δ выходит за разумный бюджет — находка, не
замалчивать. Отчёт содержит: таблицу «SLO-строка → была not-checkable → теперь checkable», overhead-δ,
вердикт готовности P8-минимума как гейта.
**Code Guidance:** **Анти-самообман — сердце item'а:** «seam добавлен» ≠ «гейт сходится»; критерий —
метрика реально появилась в выхлопе харнесса с верным типом/лейблами, проверенная **прогоном**, не
чтением кода. Если метрика эмитится, но лейбл разошёлся с §5 — строка гейта всё ещё not-checkable,
фиксируй как незакрытую. **Overhead:** мерить на том же fingerprint (lab-box cpuset, L-1…L-7 P2.8),
иначе δ — шум окружения, не инструментации. If-then: overhead > бюджета SLO класса B → находка в §7 +
эскалация (sampling/редизайн), не «приемлемо по ощущению».
**Validation:** `findings/P8.7-gate-closure.md` существует; список эмитированных метрик ⊇ 50 из §5
(машинная сверка, 0 дыр); таблица «not-checkable → checkable» покрывает 66 строк; overhead-δ измерен
двумя прогонами и признан в бюджете (или заведён находкой). Harness exit по классу A — 0.
**Deliverables:** `findings/P8.7-gate-closure.md` (сверка 50/50, таблица закрытия, overhead-δ, вердикт).
