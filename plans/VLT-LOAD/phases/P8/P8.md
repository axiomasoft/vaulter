# P8 — Наблюдаемость: метрики + трейсы (seam'ы с нуля) (гейт P3–P7 по минимуму)

## Phase Context

**Цель.** Узнавать о нагрузке из метрик, а не от пользователей. Наблюдаемости в пакете сегодня нет
(ни Horizon, ни spatie-health, ни `/up`, ни метрик, ни трейсинга — `plan.md` §1.2) — фаза **создаёт
seam'ы**, а не подключает дашборд к существующему. Это **единственный код-выход VLT-LOAD** в пакетный
`src/` (D-LOAD-4).

**Что именно реализуем — уже решено, не изобретаем здесь.** Список P8-минимума — **50 metric families**
в 40 строках (12/10/28) — выведен из колонки «Prometheus-метрика» таблицы `slo-gates.md` **§5** (тип и лейблы каждой строки
обязательны, D9/D16). Фаза их **реализует**, а не переопределяет: расхождение с блупринтом уже сведено в
`slo-gates.md` §5.5. Без набора **66/96 строк гейта = `not-checkable`** (доказано прогонами P2.7 на S0 и
P2.8 на тире S) — поэтому P8-минимум **гейт** P3–P7, а не фоновая фаза.

**Ключевое архитектурное решение (D35).** Seam — **узкий vaulter-owned контракт `MetricsRecorder`**
(как `AzgardGuard`: `packages/core/src/Contracts/Access/AzgardGuard.php`) с `Null`-дефолтом и
`Fake` для тестов, **без хард-зависимости на OTel/Prometheus**. Хост биндит реальный адаптер;
OTel-мост — опционален (против `open-telemetry/api`, который сам no-op без SDK — RAG-15). Пакет
собирается и PHPStan зелёный при полном отсутствии любого backend'а.

**Двухступенчатый DoD (гейт срабатывает на P8-минимуме, не на полном закрытии).**
- **P8-минимум (гейт P3–P7):** машинерия seam'а + все 50 metric families §5 + `/up`/readiness, доказанные
  `Fake`-ассертами и прогоном харнесса P2 (66/96 строк перестают быть `not-checkable`). Это P8.2–P8.7.
- **Полное закрытие фазы:** трейсы (OTel-спаны) + отложенные метрики (`blob_dedup_hit`, `webhook_dlq`
  — §5.5) донабираются **после** того, как P3–P7 показали приоритет. Это **отдельный item P8.8** —
  доска честно держит его открытым, а не прячет хвостом в Pending Work.

**Границы (D-LOAD-4/D31).** Seam'ы — **чисто аддитивная инструментация**, НЕ фиксы L-долгов: `$metrics->…()`
не меняет управляющий поток, каждый покрыт `Fake`-ассертом. Поэтому **D11 не блокирует** инструментацию
файлов с непогашенным VLT-MUT-долгом (`S3MultipartHandler`, `SweepUploadsCommand`, `MoveNodeAction`) —
`vaulter_request_peak_memory_bytes`/`vaulter_assemble_*` меряют L-01 **до** фикса (P4 меряет после).

**Опора.** `plan.md` §1.2 (наблюдаемость=absent, unbounded-scan'ы) · `slo-gates.md` §5 (50 families —
SSOT) · `packages/core/src/Contracts/Access/AzgardGuard.php` + `packages/core/src/Testing/FakeAzgardGuard.php`
(прецедент шва) · `findings/P8-rag-otel-health.md` (RAG-15/16) · skill `architect:observability-design`,
`php:dependency-injection` · D9/D16/D31/D35/D36.

**Порядок.** Стартует сразу за P2. **P8-минимум (P8.2–P8.7) обязан быть готов до старта замеров P3–P7.**
Внутри фазы: P8.1 (спека+контракт-дизайн) → **независимый Sol design-review** → P8.2 (машинерия) →
{P8.3, P8.4, P8.5} (seam'ы по §5.1/§5.2/§5.3,
независимый scope) → P8.6 (health) → P8.7 (гейт-верификация + overhead) → P8.8 (трейсы, после P3–P7).
