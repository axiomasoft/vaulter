### P8.3 — Seam'ы §5.1 — HTTP и горячие пути (12 metric families)

**Intent:** Развесить по горячим путям метрики `slo-gates.md` §5.1 через `MetricsRecorder`:
`vaulter_http_request_duration_seconds` (HTTP-middleware), `vaulter_tree_query_duration_seconds` +
`vaulter_tree_cte_anchors` (seam L-06), `vaulter_subtree_nodes_touched` (seam L-06),
`vaulter_activity_feed_duration_seconds` + `vaulter_activity_write_total`, `vaulter_export_duration_seconds`,
`vaulter_collab_session_issued_total`, `vaulter_collab_snapshot_duration_seconds`, `vaulter_collab_room_active`,
`vaulter_broadcast_queue_wait_seconds`, `vaulter_upload_session_active`.
**Why:** Питает SLO-01…39 (интерактив/дерево/фид/экспорт/коллаб/upload-сессии). Без них весь класс A/B
этих строк — `not-checkable`; вдобавок `tree_cte_anchors`/`subtree_nodes_touched` — единственная приборка
L-06 (N-CTE per grant, O(subtree) move).
**Scope Included:** инструментация точек вставки из спеки P8.1 (маппинг §5.1); Fake-ассерт-тест на **каждую**
метрику (имя+тип+лейблы совпадают с §5.1); лейблы `operation`/`tier`/`outcome`/`query_kind`/`driver`/
`ability`/`protocol`/`filtered`/`verb` — дословно.
**Scope Excluded:** §5.2/§5.3 (P8.4/P8.5); health (P8.6); фикс самих L-06 боттлнеков (dev-срез, D11).
**Inputs:** `observability-spec.md` (маппинг §5.1 → файл:строка) · `slo-gates.md` §5.1 · якоря `plan.md` §1.2:
`NodeReadRepository.php:454-529` (CTE anchors), `MoveNodeAction.php:85-100` (subtree), Collaboration/*,
ActivityRecorder · контракт из P8.2.
**Files:** `packages/core/src/Http/Middleware/RecordVaulterRequestMetrics.php`; `packages/core/src/Repositories/Drive/NodeReadRepository.php`; `packages/drive/src/Actions/MoveNodeAction.php`; `packages/core/src/Http/Controllers/Activity/ActivityController.php`; `packages/core/src/Activity/ActivityRecorder.php`; `packages/documents/src/Export/NodeExportService.php`; `packages/documents/src/Collaboration/CollaborationSessionService.php`; `packages/documents/src/Actions/Collaboration/PersistYjsSnapshotAction.php`; `load/app/Http/Middleware/AssignLoadTier.php`; `load/app/Observability/CollaborationRoomMetrics.php`; `load/app/Observability/LoadStateMetrics.php`; `load/app/Listeners/RecordBroadcastQueueWait.php`; `load/app/LoadServiceProvider.php`; `load/docker-compose.load.yml` (`TIER`, service `hocuspocus`); `load/k6/scenarios/docs-collab.js` (WebSocket after token); `hocuspocus-server/src/index.js` (`GET /stats` room count); `hocuspocus-server/Dockerfile`; Fake-тесты в core/drive/documents.
**Required Reads:** (1) `observability-spec.md` (строки §5.1); (2) `slo-gates.md` §5.1; (3)
`packages/core/src/Repositories/Drive/NodeReadRepository.php:454-529`; (4)
`packages/drive/src/Actions/MoveNodeAction.php:85-100`; (5) `packages/core/src/Activity/ActivityRecorder.php`;
(6) `packages/documents/src/Collaboration/*` (issue/snapshot); (7) `FakeMetricsRecorder` из P8.2.
**Implementation Rules:** HTTP-длительность — через middleware в `vaulter-core` Http-слое, лейбл
`operation` = METHOD+path map `observability-spec.md` §9.1 (не Laravel `->name()`, не k6 OP-тег), `outcome` = класс статуса. `tier` только из host `AssignLoadTier` (compose `TIER`). `collab_room_active` — абсолютный count с hub `/stats` при живом WS; ноль без hub/клиентов запрещён. `tree_cte_anchors` инкрементируется на КАЖДЫЙ
рекурсивный CTE-спуск `candidateNodeIds()` (счётчик анкеров per-листинг). `subtree_nodes_touched` — размер
поддерева в `assertNoCycle()`. Gauge'и (`collab_room_active`, `upload_session_active`) получают только
абсолютное значение от owner/collector из P8.1; `+1/-1` не передаётся как gauge value. Все package-вызовы
— через инжектированный `MetricsRecorder`, никаких статических фасадов backend'а.
**Code Guidance:** **Аддитивность (D31):** ни одна строка существующей логики не меняется — только
добавляются вызовы `$metrics->…`. Инструментация `MoveNodeAction`/`NodeReadRepository` (несут VLT-MUT-долг)
допустима именно потому, что не трогает управляющий поток. **Анти-подгонка:** тип метрики бери из §5.1
(`tree_cte_anchors` = histogram, не counter — это распределение анкеров на листинг), не «как проще».
Каждая метрика — свой Fake-ассерт; отсутствие теста на метрику = незакрытый item. Инъекция recorder'а —
конструктором (`php:dependency-injection`), не `app()`-резолвом в теле метода.
**Validation:** `vendor/bin/pest` (по одному зелёному Fake-тесту на каждую из 12 metric families §5.1) +
phpstan max + pint --test в затронутых пакетах (core/drive/documents); ручная сверка «§5.1 (12 строк) ↔
реализованные metric families» — без дыр.
**Deliverables:** middleware + seam-вызовы в core/drive/documents по маппингу §5.1; Fake-тесты.
