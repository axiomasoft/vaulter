### P8.2 — Машинерия шва: контракт + Null-дефолт + Fake + config-wiring

**Intent:** Реализовать в `vaulter-core` сам шов без единой инструментации горячих путей:
`Vaulter\Contracts\Observability\MetricsRecorder`, `NullMetricsRecorder` (все методы no-op),
`Vaulter\Testing\FakeMetricsRecorder` (пишет эмиссии в массив + ассерт-хелперы), биндинг в
`VaulterServiceProvider::register()` (singleton, дефолт = Null), секция `observability` в
`packages/core/config/vaulter.php` (enabled-флаг, класс recorder'а).
**Why:** Все seam-item'ы (P8.3–P8.6) зависят от готового контракта и Fake — иначе их нечем ни вызвать,
ни проверить. Машинерия — общий знаменатель, её нельзя дублировать в трёх seam-item'ах.
**Scope Included:** контракт + Null + Fake + config-секция + register-биндинг по truth table
`observability-spec.md` §1 (`enabled=false` → Null; `enabled=true` + invalid/missing class → Null +
diagnostic, не exception; valid host FQCN → adapter) + тесты каждого ряда таблицы; config-cache-safety —
биндинг в `register`, не `boot`, замыкание, без резолва config во время регистрации.
**Scope Excluded:** инструментация горячих путей (P8.3–P8.5); OTel-адаптер (host/мост-пакет, не здесь);
health (P8.6); facade (запрещён D35).
**Inputs:** GREEN `findings/P8.1-design-review.md` · `observability-spec.md` (P8.1 — форма контракта) · `packages/core/src/Contracts/Access/AzgardGuard.php` /
`packages/core/src/Testing/FakeAzgardGuard.php` /
`packages/core/src/Testing/NullRoleDriver.php` (прецедент Null+Fake) · `packages/core/config/vaulter.php` (куда дописать секцию) ·
`packages/core/src/VaulterServiceProvider.php` (куда биндить).
**Files:** `packages/core/src/Contracts/Observability/MetricsRecorder.php` (новый), `packages/core/src/Observability/NullMetricsRecorder.php` (новый), `packages/core/src/Testing/FakeMetricsRecorder.php` (новый), `packages/core/config/vaulter.php` (секция `observability`), `packages/core/src/VaulterServiceProvider.php` (биндинг), `packages/core/tests/Observability/` (truth-table + Null/Fake Pest).
**Required Reads:** (1) `plans/VLT-LOAD/findings/P8.1-design-review.md` (GREEN);
(2) `plans/VLT-LOAD/observability-spec.md`; (3) `packages/core/src/Contracts/Access/AzgardGuard.php`;
(4) `packages/core/src/Testing/FakeAzgardGuard.php` + `packages/core/src/Testing/NullRoleDriver.php`;
(5) `packages/core/src/VaulterServiceProvider.php` (паттерн register/публикация config);
(6) `packages/core/config/vaulter.php`.
**Implementation Rules:** Сигнатура — дословно из P8.1/D35. `NullMetricsRecorder` — `final`:
counter/gauge/histogram ничего не пишут, а `timing()` исполняет callback и сохраняет его return/exception semantics.
`FakeMetricsRecorder` — `final`, хранит `array $emissions` со структурой `['type','name','value','labels']`
+ методы `assertCounter/assertGauge/assertHistogram(string $name, ?array $labels)`, `emissions(): array`.
Биндинг: factory в `register()` реализует truth table `observability-spec.md` §1; **не**
`$app->make($app['config']->get('vaulter.observability.recorder', NullMetricsRecorder::class))` без
чтения `enabled`. `enabled=false` выбирает Null даже если recorder class задан. Sampling для P8-minimum отсутствует. Config-секция публикуема существующим механизмом провайдера.
Контракт — `@internal` НЕ ставить (public seam, D35/P8.1).
**Code Guidance:** Применить `php:dependency-injection` и `php:repositories` (Null-object). Точный перенос прецедента `AzgardGuard` (public контракт `Contracts/`) + `FakeAzgardGuard`
(`Testing/`) — не изобретай свой стиль. **Config-cache-safety** — граба M0 S3 (память проекта): резолв
конфигурации только внутри замыкания биндинга, никогда в теле `register`. **Анти-самообман:** тест «Null
ничего не эмитит» должен проверять именно отсутствие сайд-эффекта (Fake-подмена + пустой `emissions()`),
а не просто «метод вызвался». Никаких `if (config(...))`-развилок в самих будущих seam'ах — дешёвый no-op
даёт сам Null-recorder (RAG-15). Публичный контракт → **обязателен review-гейт `vaulter-reviewer`** (BC/SemVer).
Facade не добавлять (D35).
**Validation:** `vendor/bin/pest` (новые тесты Null/Fake/резолв зелёные) + `vendor/bin/phpstan analyse`
(max, зелёный при отсутствии OTel) + `vendor/bin/pint --test` в `packages/core`; резолв
`app(MetricsRecorder::class)` без конфига хоста возвращает `NullMetricsRecorder`.
**Deliverables:** `packages/core/src/Contracts/Observability/MetricsRecorder.php`,
`packages/core/src/Observability/NullMetricsRecorder.php`, `packages/core/src/Testing/FakeMetricsRecorder.php`,
секция `observability` в `packages/core/config/vaulter.php`, биндинг в `VaulterServiceProvider`, тесты.
