### P0.0 — Рекогносцировка + RAG-провенанс + мастер-план

**Status:** 🟢 Done

**Intent:** Собрать опорные факты о горячих путях vaulter (память, конкуренция, sweeper/GC, очереди,
collab, наблюдаемость), верифицировать внешние факты об инструментах через RAG и зафиксировать
мастер-план VLT-LOAD.

**Why:** Нагрузочная программа без опоры в коде вырождается в абстрактный чеклист; без RAG — в
пересказ памяти модели про инструменты, которые с 2026 изменились.

**Scope Included:** рекогносцировка кодовой базы с якорями `file:line`; RAG-1…RAG-5 (инструмент
нагрузки, ловушка стриминга в k6, экспорт метрик, профилирование Postgres 16, очереди/OTel/chaos);
`plan.md` (секции 0–9, D1–D11); строка плана в `plans/ACTIVE.md`.

**Scope Excluded:** любые замеры и любой код (D-LOAD-4); детализация фаз (P1+).

**Inputs:** кодовая база vaulter; память проекта (mAInd, scope `project:vaulter`).

**Files:** `plans/VLT-LOAD/plan.md`, `plans/VLT-LOAD/findings/P0-rag-load-tooling.md`, `plans/ACTIVE.md`.

**Required Reads:** (ретро) `packages/drive/src/Uploads/S3MultipartHandler.php`,
`packages/drive/src/Console/SweepUploadsCommand.php`, `packages/media/src/Cas/BlobGarbageCollector.php`,
`packages/core/src/Webhooks/{OutboxRelay,WebhookRetryDispatcher}.php`,
`packages/core/src/Repositories/Drive/NodeReadRepository.php`, `packages/core/src/Schema/PanelTablesBuilder.php`.

**Implementation Rules:** внешний факт — только через RAG-лестницу, с записью в `findings/`; факт из
кода — только с якорем `file:line`.

**Code Guidance:** —

**Validation:** `plan-lint` на `plans/VLT-LOAD`; каждый якорь §1.2 резолвится в репо.

**Deliverables:** `plan.md` (D1–D11), `findings/P0-rag-load-tooling.md`, строка в `plans/ACTIVE.md`.

**Completion Notes:** Найден Blocker-кандидат L-01 (`S3MultipartHandler::complete()` держит весь файл
в RAM; `max_chunk_bytes` ограничивает один парт, не сумму) — доказан арифметикой, не прогоном (D7,
D-LOAD-5a), и заведён в `## 7. Findings-долг` со статусом «подтверждено». Ещё 7 гипотез-долгов
(L-02…L-08): unbounded-scan'ы sweeper/GC/retry-dispatcher, O(endpoints)-фильтр в PHP, N-CTE per grant,
int4-ключ CAS-лока, отсутствие расписания у фоновых команд. Наблюдаемость в пакете = ноль (ни метрик,
ни трейсов, ни `/up`) — отсюда D9: P8 не «параллельна», а гейт для P3–P7.
