**26 интерфейсов-контрактов** (core 21 / drive 1 / documents 3 / azgard 1; media 0 / filament 0) +
**один фасад** `Vaulter\Facades\Vaulter` (accessor-биндинг `'vaulter'`). Два item'а: **P2.1**
