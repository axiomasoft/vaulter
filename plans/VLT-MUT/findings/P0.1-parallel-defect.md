# P0.1 — `--parallel` делает мутационный гейт неспособным упасть

**Дата:** 2026-07-13 · **Пакет-репродьюсер:** `packages/drive` · **Плагин:** `pestphp/pest-plugin-mutate`
**v4.0.1** (одна и та же версия в `composer.lock` всех пяти пакетов) · **Severity:** Blocker

## 1. Что наблюдается

Один и тот же файл, одна и та же БД, **холодный** кэш мутаций, меняется только режим запуска:

| режим | Mutations | escaped (`UNTESTED`) | Score | wall |
|:--|--:|--:|--:|--:|
| `pest --mutate --path=src/Uploads/TusUploadHandler.php --covered-only` | 27 | **7** | **74.07 %** | 2m05s |
| то же `+ --parallel --processes=1` | 27 | 0 | 100.00 % | 1m02s |
| то же `+ --parallel --processes=4` | 27 | 0 | 100.00 % | **0.33s** |

Выжившие в честном режиме — настоящие:

```
UNTESTED  src/Uploads/TusUploadHandler.php  > Line 71:  MinToMax
UNTESTED  src/Uploads/TusUploadHandler.php  > Line 113: SmallerToSmallerOrEqual
UNTESTED  src/Uploads/TusUploadHandler.php  > Line 128: RemoveMethodCall
UNTESTED  src/Uploads/TusUploadHandler.php  > Line 171: IdenticalToNotIdentical
UNTESTED  src/Uploads/TusUploadHandler.php  > Line 171: SmallerOrEqualToSmaller
UNTESTED  src/Uploads/TusUploadHandler.php  > Line 171: DecrementInteger
UNTESTED  src/Uploads/TusUploadHandler.php  > Line 171: IncrementInteger
```

`--processes=1` тратит реальное время (≈2.3 с на мутанта — дети запускаются), но всё равно рапортует
100 %. Значит причина **не** в конкуренции воркеров за БД, а в самом флаге.

## 2. Механика

`vendor/pestphp/pest-plugin-mutate/src/MutationTest.php:48` — `start()` запускает мутанта дочерним
процессом, передавая **исходный argv родителя**:

```php
$filteredArguments = array_filter($originalArguments, fn ($a) => ! str_starts_with($a, '--coverage'));
// снимается только --coverage*; --parallel/--processes/--mutate/--path/--covered-only остаются
$process = new Process(
    command: [...$filteredArguments, '--bail', '--filter="'.implode('|', $filters).'"'],
    env: $envs,   // при --parallel: PARATEST=1, TEST_TOKEN=<1..N>, LARAVEL_PARALLEL_TESTING=1
);
```

В ребёнке `vendor/pestphp/pest/src/Plugins/Parallel.php:95` видит `--parallel` в argv:

```php
if (self::isEnabled()) {
    exit($this->runTestSuiteInParallel($arguments));  // → ParaTest
}
```

ParaTest получает argv, в котором остались `--mutate`, `--path=…`, `--covered-only`, и `--filter="…"`
с **литеральными кавычками** (Symfony `Process` с массивом argv не проходит через шелл, так что кавычки
не снимаются) → падает, не выполнив ни одного теста → **ненулевой exit code**.

Родитель (`MutationTestRunner::checkRunningTestsHaveFinished()`) трактует ненулевой exit ребёнка как
«тесты упали» ⇒ **мутант убит**. Так убиваются все мутанты, включая тех, что реально выживают.

## 3. Радиус поражения

Флаг стоит во всех пяти mutation-job'ах, версия плагина одна:

```
.github/workflows/mutation.yml:48   pest --mutate --path=packages/core/src --covered-only --parallel --processes=4 --min=95
.github/workflows/documents.yml:114 pest --mutate --path=src            --covered-only --parallel --processes=4 --min=95
.github/workflows/drive.yml:107     pest --mutate --path=src            --covered-only --parallel --processes=4 --min=95
.github/workflows/media.yml:105     pest --mutate --path=src            --covered-only --parallel --processes=4 --min=95
.github/workflows/filament.yml:92   pest --mutate --path=src            --covered-only --parallel --processes=4 --min=95
```

⇒ Зафиксированные VLT-REMED P5.9 «Score 100.00 %» (`core` 1569 / `documents` 1472 / `drive` 1569 /
`media` 380 / `filament` 189) — **артефакты**, а не измерения. Класс тот же, что у снятого Infection
(`|| true` + отсутствующий Pest-адаптер): гейт, который физически не может упасть. Отличие —
этот выглядел рабочим: тратил минуты CI и печатал зелёную цифру.

## 4. Методика честного замера (воспроизводимо)

Три ловушки, каждая по отдельности даёт ложный результат:

1. **Горячий кэш.** Кэш мутаций живёт в `vendor/pestphp/pest-plugin-mutate/.temp/pest-mutate-cache`
   (`Plugins/Mutate.php:102`) и переживает прогоны — вердикт прошлого (в т.ч. `--parallel`-прогона)
   возвращается мгновенно. На хосте он был горячим: 6893 файла / 46 МБ. Замер обязан идти на **пустом**
   кэше; в контейнере — tmpfs поверх `.temp` (и внутри `mkdir -p .temp/mutations .temp/pest-mutate-cache`,
   плагин создаёт только второй).
2. **Общая БД.** Сьют мигрирует по тесту (`RefreshDatabase`/`DatabaseMigrations`), поэтому параллельные
   прогоны роняют друг другу таблицы (`relation "v_storages" already exists`). Плюс upload-секции берут
   `pg_advisory_xact_lock`, чей ключ — **на базу**, так что даже изоляция по схеме позволила бы воркерам
   бодаться за чужие локи. Нужна **база на воркер/шард**.
3. **Общий storage Testbench.** `Storage::fake('local')` кладёт staged-байты аплоада в
   `vendor/orchestra/testbench-core/laravel/storage/framework/testing/…`; при бинд-маунте одного репо
   шарды затирают друг другу staged-файлы (`StagedUploadMissingException`). Нужен tmpfs поверх
   `…/laravel/storage` (+ `bootstrap/cache`), с досозданием скелета каталогов.

Замерочный образ (локально, вне CI): `php:8.4-cli` + `docker-php-ext-install pdo_pgsql pgsql pcntl zip`
+ `pecl install pcov`. Postgres — `postgres:16-alpine`. Сборка образа требует `docker build --network=host`
(контейнеры на дефолтном bridge в этом окружении без egress).

Скрипт шардирования: `scratchpad/shard.sh` (в репо не коммитится; форма — в §5 ниже).

## 5. Форма шард-прогона

```bash
docker run --rm --network <net> -v <repo>:/app \
  --mount type=tmpfs,destination=/app/packages/<pkg>/vendor/pestphp/pest-plugin-mutate/.temp \
  --mount type=tmpfs,destination=/app/packages/<pkg>/vendor/orchestra/testbench-core/laravel/storage \
  --mount type=tmpfs,destination=/app/packages/<pkg>/vendor/orchestra/testbench-core/laravel/bootstrap/cache \
  -w /app/packages/<pkg> \
  -e DB_CONNECTION=pgsql -e DB_HOST=<pg> -e DB_DATABASE=<своя_база_на_шард> … \
  <image> bash -c 'mkdir -p …/.temp/mutations …/.temp/pest-mutate-cache \
     …/storage/framework/{cache/data,sessions,testing/disks,views} …/storage/logs …/storage/app/public \
   && vendor/bin/pest --mutate --path=src/<Shard> --covered-only'
```

Аггрегация: `Score = (killed + timeout) / (killed + timeout + untested)`; `untested` в терминах Pest =
**выживший** мутант.
