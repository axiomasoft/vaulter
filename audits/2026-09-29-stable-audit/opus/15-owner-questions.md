# 15 — Вопросы владельцу (с решением по умолчанию)

Каждое решение уже принято в [02-decisions.md](02-decisions.md) и действует, если владелец не ответит иначе.
Здесь собраны пункты, где продуктовый факт или вкус владельца может изменить план.

| # | Вопрос | Решение по умолчанию | Что меняется при другом ответе |
|---|---|---|---|
| Q1 | Выпускать исправления F1 отдельным релизом 0.2.1? | Да, если у 0.2.0 есть внешние установки; иначе F1 входит в 0.3.0 | Порядок миграций (08 §3, примечание) |
| Q2 | Есть ли production-данные 0.2 (особенно blobs в `snull/tnull`, кастомные `table_names`/`tenant.column`, own-tables панели)? | Считаем «возможно»: строгий preflight, upgrade-миграции и `repair-scopes` обязательны | Можно упростить миграции до пересоздания схемы |
| Q3 | `Reader` не может комментировать (добавить бит `Comment`) — D11 | Да | Оставить текущую семантику и удалить уровень `Commenter` |
| Q4 | Удалить own-tables режим профилей — D05 | Да | Режим надо довести до рабочего в рантайме (отдельный большой пункт) |
| Q5 | Удалить типы документов `table` и `template` — D15 | Да, данные мигрируют в `vaulter/rich-text` | Добавить два встроенных типа-пресета |
| Q6 | `auth:sanctum` в стеке `authenticated` по умолчанию | Да | Другое значение по умолчанию; doctor всё равно требует auth-middleware |
| Q7 | Удалить Reverb-драйвер коллаборации (deprecated для Yjs в 0.2) | Да; Reverb остаётся для уведомлений (broadcast) | Сохранить драйвер и добавить в него epoch/read-only |
| Q8 | Webhooks — надёжный журнал: ошибка записи outbox откатывает мутацию — D22 | Да | Best-effort с явным ограничением и командой восстановления |
| Q9 | Будет ли тегированный релиз AzGuard к 0.3? | Неизвестно → `vaulter-azgard` выходит, когда появится тег | — |
| Q10 | `DELETE v1/nodes/{node}` = окончательное удаление (только из корзины) | Да | `DELETE` = в корзину, purge — `POST …/purge` |
| Q11 | Автоматическая регистрация задач в планировщике включена по умолчанию | Да (`vaulter.schedule.enabled`) | Выключено; doctor напоминает |
| Q12 | MySQL — «поддерживается» (smoke + инварианты) | Да | «Best effort», без гейта |
| Q13 | Сохранять Laravel 12 до 1.0 | Да | Только Laravel 13 → меньше матрица |
| Q14 | Хранить OpenAPI вручную (не генерировать из кода) | Да | Генерация из аннотаций — дополнительная зависимость |
| Q15 | Префикс ключей расширений `vaulter/` для встроенных | Да | Короткие ключи без vendor для встроенных |

## Не вопрос, а действие владельца

- Подключить проект к mAInd и занести ключевые решения D01–D40 в память `project:vaulter` — из облачного
  контейнера этой сессии `maind` недоступен (`command not found`), поэтому связь не проверена.
- Перевести ADR 0019–0024 (пункт P0.4) из `proposed` в `accepted` после чтения.
